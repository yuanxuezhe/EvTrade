### 项目概况
- **定位**：A股智能交易终端
- **技术栈**：Vue 3 + FastAPI + msgpacket RPC + XtQuant/QMT 柜台
- **四大服务**：EvTrade API (:8000) / hqserver (:8765) / strategy_exec (:8001) / 前端 (:50998)
- **数据层**：SQLite (本地业务数据) + MySQL (策略共享表) + RabbitMQ (RPC + signal)
- **鉴权**：JWT + RBAC (admin/trader/viewer)
- **开发流程**：spec-driven (openspec/)

### 六大功能域
1. 交易核心：下单/撤单/持仓/资金/成交，走 QMT 柜台 RPC
2. T0 快速做T：任务管理 + 统计聚合 + 配额框架
3. 策略引擎：Python 脚本开发 + Backtrader 回测/实盘 + signal 推送
4. 行情数据：独立 hqserver WS FANOUT + 子串匹配订阅 + 内存 cache
5. 系统管理：日初初始化 + 对账 + 用户管理 + 系统配置
6. 数据同步：股票信息爬虫 + 证券同步 + IndexedDB 前端缓存

### 关键架构决策
- 行情与交易解耦：hqserver 独立进程，不经过 EvTrade API 转发
- 策略引擎独立服务：strategy_exec 基于 Backtrader，通过 RabbitMQ 推 signal
- ORM → tables 迁移：禁止直接 db.query，统一走 server/tables/* 接口
- WebSocket 5 频道：order/trade/position/quote/system_update
