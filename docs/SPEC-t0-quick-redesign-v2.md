## 0. 触发原因 (Why v2)

v1 设计完后用户测试反馈:
> 当前设计不满意, 我想整体是一个表格形式, 展示持仓相关信息, 在后面接上做T的相关操作,
> 一键买卖、配平等, 点击能在右侧展开一个窗口, 展示做T明细、收益等详细信息

**核心问题**: v1 仍保持 7 卡 + 1 表的"卡片墙"布局, 没体现"表格驱动"的设计哲学.

## 1. 关键差异 (v1 → v2)

| 维度 | v1 | v2 |
|------|----|----|
| 布局哲学 | 7 卡 + 1 表 (卡片墙) | **1 主表 + 1 抽屉** (表格驱动) |
| 持仓可见性 | 表 (主)+ 弹窗 (picker) | **整张表** (无弹窗) |
| 做T 数据位置 | 4 张独立卡 (敞口/累计/历史/...) | **全部进抽屉**, 按 per 标的 隔离 |
| 快捷入口 | 行内 [买 N%][卖 N%] (8 按钮/行) | **抽屉内集中** (4档买 + 4档卖 + 配平) |
| 点击行为 | 弹 Picker 改 stockCode | **整行可点 + 操作列 [→]** 打开抽屉 |

## 3. 主表 8 列定义 (v2)

| # | 列名 | 字段 | 来源 | 备注 |
|---|------|------|------|------|
| 1 | 代码 | `row.stock_code` | positions | el-link 点击复制 |
| 2 | 名称 | `row.stock_name ?? code` | positions / 静态映射 | 兜底用 code |
| 3 | 持仓 | `row.vol` | positions | 千分位 + 红涨绿跌 |
| 4 | 现价 | `quoteStore.getLastPrice(code)` | quote | 涨绿跌红 |
| 5 | 涨跌幅 | `changePct` | quote | 百分比 + 色 |
| 6 | 今日净 | `t0Stats.today_buy_volume - t0Stats.today_sell_volume` | t0_stats API | 正绿负红 |
| 7 | 累计收益 | `t0Stats.realized_pnl` | t0_stats API | 数字 + 色 + ¥ |
| 8 | 操作 | `[→]` 按钮 | -- | 点击开抽屉 |

## 4. 抽屉触发与默认

| 场景 | 默认 |
|------|------|
| 首次进入 T0 页 | 第一个持仓行 **自动展开**（保证抽屉内数据非空）|
| 点行 / [→] 按钮 | 切换到该行的标的 |
| 切换 stockCode | 抽屉内 stats/exposure/history 全部重新加载 |
| 关闭抽屉 | 隐藏, 不清状态 (下次打开恢复) |

## 5. 顶部设置条与抽屉交互

顶部条 (commit 2 已做, 保留) 提供的 `quickPct` / `quickPriceType` 同样驱动抽屉的 [25%买] 等按钮:
