# Vue交易系统设计方案

## 1. 项目概述

**项目名称**: EvTrade Web
**项目类型**: Vue3 前端 + Python FastAPI 后端
**核心功能**: 交易管理、做T操作、持仓与资金管理
**目标用户**: 手动交易员、策略运维人员

## 3. 核心数据结构

### 3.1 持仓结构 (Position)

| 字段 | 类型 | 说明 |
|------|------|------|
| stockCode | string | 股票代码，如 "000001.SZ" |
| stockName | string | 股票名称 |
| initialPosition | int | 期初持仓（日初初始化时设置） |
| todayBuy | int | 当日买入股数 |
| todaySell | int | 当日卖出股数 |
| available | int | 可用 = 期初 - 今日卖出 + 今日买入 |
| total | int | 总持仓 = 期初 + 今日买入 - 今日卖出 |

### 3.2 委托结构 (Order)

| 字段 | 类型 | 说明 |
|------|------|------|
| orderId | string | 委托号 |
| stockCode | string | 股票代码 |
| direction | string | BUY / SELL |
| volume | int | 委托数量 |
| price | float | 委托价格 |
| priceType | string | 价格类型 |
| status | string | pending / filled / cancelled / rejected |
| tradedVolume | int | 已成交数量 |
| tradedPrice | float | 已成交价格 |
| orderTime | string | 委托时间 |

### 3.3 成交结构 (Trade)

| 字段 | 类型 | 说明 |
|------|------|------|
| tradeId | string | 成交号 |
| orderId | string | 对应委托号 |
| stockCode | string | 股票代码 |
| direction | string | BUY / SELL |
| volume | int | 成交数量 |
| price | float | 成交价格 |
| tradeTime | string | 成交时间 |

### 3.4 资金结构 (Asset)

| 字段 | 类型 | 说明 |
|------|------|------|
| cash | float | 可用资金 |
| frozenCash | float | 冻结资金 |
| marketValue | float | 持仓市值 |
| totalAsset | float | 总资产 |

## 4. 页面设计

### 4.1 持仓页面（主页）

入口页面，展示所有持仓，支持日初初始化。

**布局：**
```
┌──────────────────────────────────────────────────────────────┐
│  持仓管理 [日初初始化]     │
├──────────────────────────────────────────────────────────────┤
│  股票代码   股票名称   期初    买入    卖出   可用   总持仓   │
│  513050.SH 纳斯指数 10000   2000    2500   9500   9500    │
│  000001.SZ 平安银行   5000    0       1000   4000   4000    │
└──────────────────────────────────────────────────────────────┘
```

**日初初始化逻辑：**
- 点击"日初初始化"按钮
- 将当前 total 复制到 initialPosition
- 重置 todayBuy = 0, todaySell = 0
- 确认对话框防止误操作

### 4.2 持仓明细面板

点击持仓列表某行后，下方展开该股的委托/成交明细。

**布局：**
```
┌──────────────────────────────────────────────────────────────┐
│  513050.SH 委托/成交明细 │
├──────────────────────────────────────────────────────────────┤
│  时间         类型   方向  数量   价格    状态    委托号     │
│  09:30:15    委托   买入  1000  12.50   成交   10001        │
│  09:31:22    成交   买入  1000  12.50   -      -            │
│  09:45:10    委托   卖出  1500  12.60成交   10002        │
│  09:46:05    成交   卖出  1500  12.60   -      -            │
├──────────────────────────────────────────────────────────────┤
│  做T收益: +¥200.00 (+0.64%)            需买回: 500股        │
└──────────────────────────────────────────────────────────────┘
```

**做T收益计算：**
- 做T收益 = (卖出均价 - 买入均价) × min(当日买入, 当日卖出)
- 配平提示 = 期初持仓 - 总持仓（负数表示需买回）

## 5. WebSocket 推送事件

| 事件名 | 说明 |
|--------|------|
| order_update | 委托状态变化 |
| trade_update | 成交回报 |
| position_update | 持仓变化 |
| asset_update | 资金变化 |

## 6. API 接口设计

### 6.1 HTTP API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/positions | 获取持仓列表 |
| POST | /api/positions/{stockCode}/init | 日初初始化 |
| GET | /api/orders | 获取委托列表 |
| GET | /api/trades | 获取成交列表 |
| GET | /api/asset | 获取资金信息 |
| POST | /api/orders | 下单 |
| DELETE | /api/orders/{orderId} | 撤单 |

### 6.2 WebSocket

| 事件 | 方向 | 说明 |
|------|------|------|
| subscribe | 客户端→服务端 | 订阅事件类型 |
| order_update | 服务端→客户端 | 委托变化推送 |
| trade_update | 服务端→客户端 | 成交变化推送 |

## 8. 技术栈

###8.1 前端
- Vue 3 + Composition API
- Pinia（状态管理）

- Element Plus（UI组件库）

- Python 3.9+
- FastAPI（HTTP API）
- WebSocket Server
- aio-pika（RabbitMQ RPC Client）
- xtquant（交易API）
