# 快速做T 页面重新设计 (M-009)

> 创建日期：2026-06-29
> 状态：draft
> 范围：重写 [client/src/views/T0Trade.vue](../../client/src/views/T0Trade.vue)

## Why

**用户原话**："快速做T页面优化，主体是按持仓的一个表格，要素都在表格行里面。不要在表格下面另外展示。帮我设计一个更合理便捷的设计"

**诊断**（参考 [brainstorming](skills/brainstorming) 流程）：

| 当前布局问题 | 严重度 |
|---|---|
| 主表只占视口 25%，下面 7 个堆叠卡片 (敞口/T0 成本/预期收益/exposure-card/一键动作/配平计算/仓位建议) | **核心** |
| "持仓敞口 / T0 成本 / 预期收益" 3 个 metric-card 高度重复 (cost 出现 3 次, realized_pnl 出现 3 次) | 高 |
| "一键动作卡" 硬编码 600519.SH 茅台 — **严重的耦合 bug** | **核心** |
| 3 处配平入口 (行内/底部/敞口表)，3 套算法 | 中 |
| 移动端 5 列 + 170px 操作列 + sticky header → 按钮文字被挤 | 高 |
| 累计曲线在抽屉和主区底部各一份 — 重复 | 中 |
| 用户原话"该看到今盈/浮盈的位置"是行内，但目前在抽屉+底部 | **核心** |

## What

**用户拍板**：方案 2（中量行内仪表）+ 全部删底部卡 + 设置条放标题右侧 + 移动端卡片式

### 新设计 (桌面)

```
┌──────────────────────────────────────────────────────────────────┐
│  ⚡ 快速做T                              [仓位%] [价格档]  刷新  │ ← 标题 + 设置条
├──────────────────────────────────────────────────────────────────┤
│ 主表 (占视口 100%, max-height = 100vh - 标题高度)               │
│ ┌────────────────────────────────────────────────────────────┐  │
│ │ 代码 名称  持仓  现价  涨跌  今盈  净敞口  浮盈%  操作      │  │ ← 主行 (40px)
│ ├────────────────────────────────────────────────────────────┤  │
│ │ 副行 (可展开, 默认展开, 28px 高)                            │  │
│ │ 成本  成本额  今笔  胜率  [30天 mini-sparkline]              │  │
│ └────────────────────────────────────────────────────────────┘  │
│  [买 X%] [卖 X%] [配平 ±N] [详情 →]                              │ ← 操作按钮 (在主行最右)
├──────────────────────────────────────────────────────────────────┤
│ 底部: 当前选中标的 30 日累计曲线 (80px 高, 7/30/90D 切换)        │ ← 唯一保留的"额外展示"
└──────────────────────────────────────────────────────────────────┘
```

### 表格每列

| 列 | 宽度 | 内容 | 来源 |
|---|---|---|---|
| 代码 | 80px | 股票代码 | `row.stock_code` |
| 名称 | 80px | 股票名 | `row.stock_name` |
| 持仓 | 70px | 总持仓量 | `row.vol` |
| 现价 | 80px | 数字, 涨红跌绿 | `quoteStore.getLastPrice()` |
| 涨跌幅 | 70px | % | `quoteStore.getChangePct()` |
| **今盈** | 90px | ±¥ (今日已实现) | `t0Stats.realized_pnl` (按需) |
| **净敞口** | 80px | ±N (今日买-卖) | `t0Stats.today_buy_volume - today_sell_volume` |
| **浮盈%** | 70px | (现价-成本)/成本 | `holdingsStore.getReturnRate()` |
| 操作 | 200px | 4 按钮 (买/卖/配平/详情) | - |

### 副行（默认展开）

| 元素 | 宽度 | 内容 |
|---|---|---|
| 成本 | 90px | `row.cost_price` |
| 成本额 | 100px | `cost_price * vol` |
| 今笔 | 70px | `t0Stats.trade_count` |
| 胜率 | 70px | `t0Stats.win_rate` |
| Sparkline | 150px | 30 日累计 mini-curve |

### 操作列 4 按钮

- **买 X%** (绿)：按 quickPct 全局仓位买入，0 持仓时灰显
- **卖 X%** (红)：按 quickPct 卖出，0 持仓时灰显
- **配平 ±N** (橙)：按钮文本动态显示数量（"配 +200" / "配 -200"），0 净敞口时灰显
- **详情 →** (link)：打开右侧抽屉 (历史曲线 + 累计统计)

### 移动端 (≤768px)

- 主行 4 列：代码+名称 / 现价 / 涨跌 / 操作 3 按钮横滑 (Pinterest 式)
- 副行折叠到"点行展开"
- 累计曲线折叠为底部 Tab (默认隐藏)

### 删除项

| 元素 | 原因 |
|---|---|
| 3 个 metric-card (敞口/T0 成本/预期收益) | 数据重复 + 占用屏幕 |
| exposure-card (敞口聚合表 + 全账户配平) | 与行内"净敞口 + 配平"重复 |
| 一键动作卡 (硬编码 600519.SH) | **严重 bug**，与行内按钮重复 |
| 配平计算卡 | 与行内"配平"按钮重复 |
| 仓位管理建议卡 (4 档 profile) | 配置项，移到设置抽屉 |
| 底部重复的累计曲线 | 抽屉已有，仅保留底部一份（按当前选中标的） |

### 保留项

| 元素 | 原因 |
|---|---|
| 设置条 (仓位% + 价格档) | 移到标题右侧 |
| 顶部"快速做T"卡片 | 简化为 header + 设置条 |
| 主表 + 4 按钮 (买/卖/配平/详情) | 核心 |
| 抽屉 (历史曲线 + 累计统计 + 30 日明细) | 复盘用 |
| 底部单标的累计曲线 (80px) | 唯一额外展示 |
| 快捷键 B/S/F | 桌面端效率 |
