# REQ-FE-552: 主图再瘦身 — layout 拆 lazy + 整包改子路径 (2026-09-23 bundle-shrink-round-2)

## 背景

`REQ-FE-551` 已把 `element-plus` 主 deps 1.2 MB → 88 KB (13.6×), 但 curl 实测瀑布发现:
- `client/src/components/AppHeader.vue` (61 KB) / `OperationLog.vue` (30+ KB) / `views/Login.vue` 等
  仍写 `import { ElMessage, ElMessageBox } from 'element-plus'` (整包路径),
  触发 vite deps prebundle 出 `element-plus.js?v=…` 88 KB 重新回到 waterfall,
  并让 unplugin 在文件头插 `/* unplugin-vue-components disabled */` marker, 模板里 el-* 不按需注入.
- App.vue 静态 import 了 4 个 layout component (Sidebar / AppHeader / OperationLog / BottomNav),
  无论路由去哪个 page 都要先 mount layout, 拉 4 个 component + 它们引的 store / el-icon.

## 新增规范

### REQ-FE-552.1: layout 4 组件必须 `defineAsyncComponent` 异步加载

`client/src/App.vue` 引用 `./components/{Sidebar,AppHeader,OperationLog,BottomNav}.vue` 必须
经 `defineAsyncComponent(() => import('...'))` 包装, 不能再用静态 `import`. v-if 控制
的展示时机会让 component 在 v-if=true 后才 fetch, 首屏主图瘦 ~50 KB.

### REQ-FE-552.2: 禁止 `from 'element-plus'` 整包路径

业务文件需要 `ElMessage` / `ElMessageBox` / `ElNotification` / `ElLoading` 等 API 时:

```js
import { ElMessage } from 'element-plus/es'                  // ✅ 子路径, ESM entry
import { ElMessage, ElMessageBox } from 'element-plus/es'    // ✅
import { ElMessage } from 'element-plus'                     // ❌ 整包, 触发 REQ-FE-551 disabled
```

### REQ-FE-552.3: 派生的 unplugin 校验

改完子路径后, 原本文件头插的 `/* unplugin-vue-components disabled */` marker 会消失,
模板里 `<el-button>` / `<el-icon><Edit /></el-icon>` 重新被 resolver 自动按需注入.

### REQ-FE-552.4: 保留 eager 的部分 (拍板存档)

- App.vue 顶层 5 store (`ui/auth/ws/holdings/stocks`) 必须 eager — 启动屏障 + bootstrap 必需
- 5 个 WS 频道 + `/api/asset/holdings/quote/snapshots` 业务数据登录后必需
- `element-plus/dist/index.css` 整包 CSS (gzip ~30 KB) 保留, css 按需 .scss loader 复杂度不值
- `@element-plus/icons-vue` 整包 ESM (70 KB) 暂不优化 — per-file 按 icon 拆包需要 unplugin-icons
  resolver + 散开 30 个文件 import 路径, ROI 不划算

## 验证 (curl 实测 50998)

| 资源 | 改前 | 改后 |
|---|---|---|
| `element-plus.js` (deps 整包) | 88 KB / 5ms | **不出现** |
| AppHeader bytes | 61 KB | ~30 KB |
| OperationLog bytes | 30+ KB | ~5 KB |
| unplugin disabled marker | 3 文件 | **0 文件** |
| 主图 (HTML + main + App.vue) | — | 显著瘦 |
