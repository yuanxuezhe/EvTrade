# REQ-FE-551：element-plus 必须按需引入（2026-09-23）

## 背景

`client/src/main.js` 当前对 element-plus 与 @element-plus/icons-vue 都是**全量**引入，
导致 vite dev 与生产 bundle 都包含 100+ el-* 组件 + 280+ 图标组件，单 element-plus.js ≈ 1.2 MB，
首屏 wall-clock 加载 ≈ 665ms 该单文件（curl 实测 50998）。

## 新增规范

### REQ-FE-551.1：main.js 禁止 element-plus 全量导入

禁止在 main.js 或任何顶层 module 里写：

```js
import ElementPlus from 'element-plus'                  // 禁止
import * as ElementPlusIconsVue from '@element-plus/icons-vue'  // 禁止
for (const [key, c] of Object.entries(ElementPlusIconsVue))  // 禁止全量循环
  app.component(key, c)
```

正确做法：**vite.config.js 配置 unplugin-vue-components + ElementPlusResolver**，
业务 .vue 模板里的 `<el-button>` / `<el-icon><Edit /></el-icon>` 由 resolver 在 transform 时
自动按需注入 `import { ElButton }` / `import { Edit }`，产物只包含真正用到的组件 + 图标。

### REQ-FE-551.2：图标必须用 PascalCase 静态标签

resolver 只能在 transform 时看到静态标签名，**`<component :is="dynName">` 形式的动态图标名
不会触发按需 import**，会运行时报 "component not registered"。

禁止：`<el-icon><component :is="someIcon" /></el-icon>` 用于图标。
允许：`<el-icon><Edit /></el-icon>`、`<el-icon><Setting /></el-icon>` 等 PascalCase 静态标签。

### REQ-FE-551.3：i18n locale 仍需保留（zhCn）

ElementPlusResolver 只接管组件 import + register，**不接管 locale**。
`app.use(ElementPlus, { locale: zhCn })` 在改按需引入后删除，
需要单独配置 ElementPlus 的中文 locale，否则 el-pagination / el-table 等内置文案会回退英文。

允许做法：

```js
import zhCn from 'element-plus/dist/locale/zh-cn.mjs'
// 选择其一：
app.use(ElementPlus, { locale: zhCn })  // 只引一个 ElLoading 占位即可触发 locale
// 或
app.config.globalProperties.$ELEMENT = { locale: zhCn }
```

### REQ-FE-551.4：element-plus CSS 引入策略

CSS 暂时沿用 `import 'element-plus/dist/index.css'`（单文件 200KB，gzip 后小）。
如未来发现 CSS 也过大，开启 `ElementPlusResolver({ importStyle: 'css' })`
由 unplugin 自动按需插入组件级 .css 引入。

### REQ-FE-551.5：vite.config.js 必填项

```js
import Components from 'unplugin-vue-components/vite'
import { ElementPlusResolver } from 'unplugin-vue-components/resolvers'

plugins: [
  vue(),
  Components({ resolvers: [ElementPlusResolver()] }),
]
```

不允许在 vite.config.js 用 `optimizeDeps.include` 强制预打包 element-plus 全量
（与本规范冲突，会抵消按需收益）。
