# 前端架构概览

## 对应代码路径

- `client/src/main.js`、`client/src/App.vue`
- `client/vite.config.js`、`client/package.json`
- `client/src/api/`（http.js、index.js、admin.js、stocks.js、sync.js、sysconfig.js、t0_stats.js、t0_tasks.js、script_strategy.js、stkpool.js、ai_analysis.js）
- `client/src/composables/`、`client/src/constants/`、`client/src/utils/`、`client/src/lib/`、`client/src/directives/`（t0Badge.js）、`client/src/modules/`（空目录）

## 功能概述

EvTrade 前端是 A 股智能交易终端的 SPA，技术栈为 Vue 3（Composition API）+ Pinia（setup 语法糖 store）+ Vue Router 4 + Element Plus + ECharts。核心设计原则：

1. **单一权威缓存源**：holdings store 持有 orders/trades/positions/asset，其余 store（order/position/asset）均为 facade，零数据漂移。
2. **IDB 秒开**：orders/trades/positions/stocks/session 均落 IndexedDB，F5 后先本地渲染再增量校准。
3. **WS 推送驱动**：6 个 channel 独立连接，行情/委托/成交/资产/任务进度全部推送更新，REST 只做 bootstrap/兜底。
4. **前端独立计算**：委托状态推断（inferOrderStatus）、当日盈亏（t0-calc）均与后端逐行镜像，推送只带元数据。

## 核心实现

### 启动屏障（main.js + App.vue）

```js
// main.js：同步挂载（无顶层 await），另注册全局 v-t0-badge 指令
app.use(pinia).use(router).use(ElementPlus, { locale: zhCn }).mount('#app')

// App.vue onMounted：await auth.hydrate() 从 IDB 恢复 session
if (!authStore.ready) await authStore.hydrate()
// hydrate 之所以放 App.vue onMounted（而非 main.js 顶层）：module scope 无
// active Pinia effect scope，useAuthStore() 会报错；onMounted 有 scope。
```

首轮路由守卫能读到登录态靠的是 auth store 初始化时同步读 localStorage（token: 'evtrade-token'，user: 'evtrade-user'）。主题在 mount 之后读 `localStorage('evtrade-theme')`，为 dark 时给 `documentElement` 加 class。

### App.vue 启动流程与布局

- `isBlankLayout`（`route.meta?.layout === 'blank'`，如 /login）渲染空布局。
- 已登录 onMounted：`authStore.hydrate()`（未 ready 时）→ `fetchMe()`（有 token 无 user 时）→ `holdingsStore.bootstrap()` + `_startWatchers()` → `stocksStore.initCache()`。
- `watch(isAuthenticated)` 切换 WS connect/disconnect。
- 30s HTTP 心跳已删除，改为 WS 30s 客户端 ping（见 行情与WS.md）。
- 桌面布局：Sidebar + AppHeader + OperationLog；移动端（≤900px）BottomNav。

### axios 拦截器（api/http.js 与 index.js 共享同一套代码）

```
请求拦截:  Authorization: Bearer <token>（localStorage 'evtrade-token'）
响应拦截:  _isRpcResponse({code,msg,list|data}) 识别 RPC 信封
  ├─ code !== 0 → ElMessage.error(msg) + reject
  └─ code === 0 → res.data = body.list ?? body.data ?? body   （展平，调用方直接拿数组）
错误拦截:  401 → 清 token + onUnauthorized()（router 注册的 setUnauthorizedHandler）
          >=400 → 提取 detail.msg 弹错；503 兜底提示
```

### 构建配置（vite.config.js）

### IndexedDB 缓存策略总览

| DB（自动加 `EvTrade-` 前缀） | store | key | 用途 |
|---|---|---|---|
| auth | kv | `session` | token + user 持久化 |
| holdings-cache (v5) | orders | `${trd_date}:${order_no}` | 当日委托缓存 |
| holdings-cache | trades | `${trd_date}:${order_no}:${trade_id}` | 当日成交缓存 |
| holdings-cache | positions | inline `stock_code` | 持仓缓存 |
| stocks (v2) | stocks | `stock_code` | 全量证券信息（逐条 key） |

统一走 `utils/idb.js` 薄封装：openDB 连接复用、idbGet/idbPut/idbDelete/idbClear/idbGetAllKeys/idbGetAll；IDB 不可用（Node 测试/隐身模式）时静默降级，不阻塞主流程。

| 模块 | 职责 |

| useT0DayPnl | 当日盈亏：refresh 拉成交聚合 map + getDayPnl 单标的计算（不 import holdings 防循环依赖） |
| useT0Quota | 账户级 quota 概览（5 pill：现金/冻结/T+0 可用/今盈） |
| useT0TradeButtons | 主表 4 按钮的 disabled + tooltip 纯函数计算 |
| useT0ChartGeometry | T0 收益曲线 SVG path 几何 |
| useT0Keybindings | T0Trade 5 键快捷键（B/S/P/↑↓/Enter，uiStore 可 opt-out） |
| usePricePrecision | 按 stockScale(code) 的响应式价格精度 + 顶层 formatPrice |

### constants 概览

- `priceType.js`：柜台协议码 PriceType（FIX_PRICE=11 / LATEST_PRICE=5 / MARKET_PEER_PRICE_FIRST=44，对齐 xtconstant）+ OrderType（买 23 / 卖 24）+ priceTypeOptions。
- `riskProfile.js`：T0 风险 4 档（conservative/balanced/aggressive/extreme），含单股仓位上限、预留现金、建议系数。

### utils / lib 概览

- `format.js`：金额/价格/百分比格式化 + 委托状态字典（STATUS_LABEL/STATUS_TYPE/STATUS_RANK/TERMINAL_STATUSES）+ inferOrderStatus（后端镜像的状态推断）。
- `orderCalc.js`：5 个纯函数——normalizeTrade / recomputeOrderFromTrade / metaMerge / flattenCancelledByRow / normalizeOrder（前端独立累计成交、推断状态）。
- `idb.js`：IndexedDB 薄封装。
- `logger.js`：console + localStorage ring buffer（1000 条），挂 `window.__evtradeDownloadLog()` 等调试 API。
- `date.js`（shiftDateStr）、`priceFormat.js`（fmtPrice/fmtAmount）、`stockNames.js`（code→name 查 stocks cache）、`tableColumns.js`（6 类通用列常量）、`trdDateFilter.js`（按日/区间筛选）。
- `lib/t0-calc.js`：快速做T 零依赖纯函数层（roundToLot / calcInsufficientCash / calcDayPnl 等，边界值全转 0 不抛）。

## 依赖关系

- main.js → router → Pinia；auth.hydrate 由 App.vue onMounted 调用（非 main.js 顶层）。
- App.vue → auth / holdings / stocks / ui / ws 系 store。
- 所有 api/*.js 复用 index.js 的 `http` axios 实例（拦截器唯一）。
- composables → stores（quote/holdings/asset/stocks）+ lib/t0-calc；holdings_daypnl 反向引用 composables/useT0DayPnl（单向，无环）。
- stores → utils/idb.js、utils/orderCalc.js、utils/format.js。

## 修改指南

- **新增 RPC 接口**：在对应 api/*.js 加方法即可，响应已被拦截器展平，直接拿数组/对象；不要新造 axios 实例。
- **新增页面**：router/index.js 注册路由 + App.vue 布局判断；需要登录的页不写 meta.public。
- **改缓存 schema**：只改对应 store 的 idb 模块（如 holdings_idb.js），版本号 +1 并写 onUpgrade 迁移；utils/idb.js 是通用层，一般不动。
- **改状态推断/累计逻辑**：只改 utils/orderCalc.js + utils/format.js 的 inferOrderStatus，必须与 `server/services/order_status.py` 保持逐行一致。
- **改价格类型协议**：constants/priceType.js 是唯一码表来源，勿在视图层硬编码数字。
