# 交易组件

## 对应代码路径
- `client/src/components/trade/`（TodayOrdersPanel.vue、HoldingsPanel.vue 等）
- `client/src/components/OrderForm.vue`、`PositionTable.vue`、`PositionDetail.vue`、`QuotePanel.vue`、`users/` 子目录

## 功能概述
交易工作台专用组件：下单表单、行情面板、持仓面板、当日委托成交、持仓表格与明细。

## 文件清单
| 代码文件 | 作用 |
|----------|------|
| `OrderForm.vue` | 下单表单：StockCodePicker + 数量/价格 + PriceTypeInput + 买/卖提交（orderStore.placeOrder） |
| `QuotePanel.vue` | 实时行情面板：最新价/涨跌幅/五档（quote store 订阅驱动） |
| `trade/HoldingsPanel.vue` | 持仓面板（Trade.vue 右上，承担 /holdings 页职责） |
| `trade/TodayOrdersPanel.vue` | 当日委托/成交双 tab + 可撤单（白名单 50/55） |
| `trade/T0TaskList.vue` / `T0TaskDetail.vue` / `T0TaskCreateDialog.vue` | T0Trade 页任务表 / 任务详情 / 创建任务弹窗 |
| `PositionTable.vue` | 持仓表格（实时市值/盈亏/收益率列） |
| `PositionDetail.vue` | 持仓明细抽屉（仅展示，无调平入口） |
| `users/` | Users.vue 配套子组件（UserEditDialog.vue / UserResetPwdDialog.vue） |
| `strategy/` | ScriptDev/ScriptTask 配套：BacktestForm.vue（回测表单）、BatchTasksTable.vue（批次任务表）、TaskDetail.vue（任务详情） |
| `strategy-order/` | StrategyOrder.vue 编排的 5 个子组件（CreatePanel/List/Detail/Children/Status，策略母单管理） |

## 核心实现

### OrderForm 提交链路
```text
校验（标的/数量/价格/整手）→ orderStore.placeOrder(payload)
→ POST /api/orders/place → 解包 list[0] → holdings.applyOrderPush(order, 'open') → ord_cfm 推送跟进
```
- 数量约束：trade_unit 整手、min_buy_qty 下限（与后端 guards 一致）

### QuotePanel
- 订阅当前 stock_code（quote store subscribe 协议）；读 quote.fields（FIELD 索引常量，LAST/PREV_CLOSE/OPEN/HIGH/LOW/五档），prev_close 驱动涨跌幅；开/高/低可点击带入委托价

### TodayOrdersPanel 撤单
- 仅 status ∈ {50 已报, 55 部成} 显示撤单按钮 → orderStore.cancelOrder(order_no, trd_date)（DELETE /api/orders/{order_no}?trd_date=…，本地乐观置 '51'）

### admin 调平
- 入口在 CachePositions.vue（/admin/cache/positions）：PUT `/positions/{stockCode}/adjust`（delta_vol/delta_avl_vol/reason）；reason 仅入 log
- `api.adjustAsset`（PUT /asset/adjust）已定义但当前无页面调用
