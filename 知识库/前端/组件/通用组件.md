# 通用组件

## 对应代码路径
`client/src/components/` 下：
- 布局：`AppHeader.vue`、`NavBar.vue`、`Sidebar.vue`、`BottomNav.vue`
- 通用：`StockCodePicker.vue`、`PriceTypeInput.vue`、`EChart.vue`、`StatCard.vue`、`OrderStatusBadge.vue`、`OperationLog.vue`、`ChangePasswordDialog.vue`、`DataTableView.vue`、`CacheTableView.vue`

## 功能概述
跨页面复用的 UI 组件：导航布局壳、标的选择器、价格类型输入、图表与卡片、状态徽章、操作流水。

## 文件清单
| 代码文件 | 作用 |
|----------|------|
| `AppHeader.vue` | 顶栏：标题、RPC 状态图标（rpc_status store）、刷新数据按钮（holdings.refreshAll）、用户菜单 |
| `NavBar.vue` / `Sidebar.vue` | 导航（按角色显隐菜单项） |
| `BottomNav.vue` | 移动端/窄屏底部导航 |
| `StockCodePicker.vue` | 标的搜索选择器：stocks store（IDB+REST）代码/拼音/名称模糊匹配 |
| `PriceTypeInput.vue` | 价格类型 numeric（11 限价/5/44 市价默认），PriceType.label(code)；随 stockCode watcher 自动填价（v127） |
| `EChart.vue` | vue-echarts 封装，自动 resize |
| `StatCard.vue` | KPI 卡片 |
| `OrderStatusBadge.vue` | 委托状态徽章（STATUS_LABEL/STATUS_TONE） |
| `OperationLog.vue` | holdings.loadHistory 操作流水展示 |
| `DataTableView.vue` | 通用表格（列配置/排序/分页/行内编辑） |
| `CacheTableView.vue` | IDB 缓存表容器（见 缓存查看器.md） |

## 核心实现

### StockCodePicker
- 数据源 stocks store；搜索匹配 utils/stockNames.js（含拼音 pypinyin 对齐后端短名）
- 选中后 emit stock_code，父组件驱动 quote 订阅

### PriceTypeInput（v127）
- numeric 价格类型与后端 orders/schemas.py 对齐；内置价格类型选项，其他页面勿自建 options

### AppHeader 刷新
- 刷新按钮 = holdings.refreshAll()（4 路 REST + 保留 ws 订阅），是"感觉数据不对"的第一诊断动作

## 依赖关系
- 上游：stocks/quote/holdings/rpc_status/ui store
- 下游：Trade/T0Trade/Dashboard/SystemInit 等几乎所有页面
