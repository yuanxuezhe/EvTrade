# 路由与权限

## 对应代码路径

- `client/src/router/index.js`（139 行，全部路由与守卫逻辑所在）
- 关联：`client/src/stores/auth.js`（守卫读取的用户态）、`client/src/api/index.js`（setUnauthorizedHandler 反向注册）

## 功能概述

使用 Vue Router 4 `createWebHistory` 模式。权限通过路由 `meta` 声明：

- `meta.public: true` — 无需登录（仅 /login）
- `meta.layout: 'blank'` — 空白布局（App.vue 的 `route.meta?.layout === 'blank'` 判断）
- `meta.requiresAdmin: true` — 仅 admin 角色
- `meta.requiresTrader: true` — admin 或 trader 角色
- `meta.title` — 页面标题，守卫中拼 `document.title = "${title} · EvTrade"`
- 其余路由 — 任意已登录用户（含 viewer）

守卫统一在 `router.beforeEach` 中实现，401 时由 api 层的 `setUnauthorizedHandler` 回调路由跳转。

### beforeEach 守卫逻辑（顺序短路）

```
0. to.meta.title → document.title = `${title} · EvTrade`
1. to.meta.public
   ├─ 已登录 且 to.path === '/login' → return { path: '/' }（防重复登录）
   └─ 否则放行
2. 未登录 → return { path: '/login', query: { redirect: to.fullPath } }
3. to.meta.requiresAdmin && !auth.isAdmin → return { path: '/' }
4. to.meta.requiresTrader && !auth.isTrader → return { path: '/' }
5. 放行 return true
```

注意：守卫对权限不足只静默跳回首页，**没有 ElMessage.warning 提示**。

角色判定来自 auth store 的 computed：`isAdmin = role === 'admin'`；`isTrader = admin | trader`；`isViewer` 为只读角色。守卫首轮能读到登录态的前提是 auth store 初始化时同步回读 localStorage（'evtrade-token' / 'evtrade-user'）；IDB 恢复由 App.vue onMounted 的 `auth.hydrate()` 完成（main.js 无顶层 await）。

### 401 与路由联动

```js
// router/index.js 模块加载时注册
setUnauthorizedHandler(() => {
  const auth = useAuthStore()
  auth.clear()                                   // 清 Pinia 用户态
  if (router.currentRoute.value.path !== '/login') {
    router.replace({ path: '/login', query: { redirect: router.currentRoute.value.fullPath } })
  }
})
```

api 层响应拦截器捕获 401 后：清 localStorage token → 调用该 handler → handler 内再清 auth store 并 replace 跳登录携带当前页，登录成功后可回跳（已在登录页则不重复跳转）。

## 依赖关系

- router → stores/auth（isAuthenticated/isAdmin/isTrader computed）。
- api/index.js → router（通过 setUnauthorizedHandler 注入的闭包，避免 api 层直接 import router 造成循环依赖）。
- App.vue → router（isBlankLayout 读 route.meta.blank；uiStore.onRouteChange 在切换时关移动端抽屉）。
- WS token 过期（4001）路径：ws_heartbeat._onTokenExpired 动态 import auth + router 跳登录，不经过守卫。

## 修改指南

- **新增需登录页面**：路由表中加一条，默认即受保护；如需 admin/trader 再加对应 meta。
- **新增公开页**：加 `meta: { public: true, blank: true }`，并确认守卫第 1 分支不会把它弹回。
- **废弃旧路径**：保留 redirect 条目（用户书签/外链兼容），不要直接删。
- **改权限模型**（如新增角色）：同步修改 auth.js 的 isTrader/isViewer computed 与守卫第 3/4 步，两处必须一致。
- **改 401 行为**：入口在 api 拦截器，路由侧只维护 handler 注册；不要在守卫里做 401 处理。
