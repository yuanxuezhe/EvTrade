# 交易下单

## 对应代码路径
- `client/src/views/Trade.vue`
- `client/src/components/OrderForm.vue`、`QuotePanel.vue`
- `client/src/components/trade/TodayOrdersPanel.vue`、`trade/HoldingsPanel.vue`、`trade/` 其他

## 功能概述
四象限布局的手动下单工作台（requiresTrader）：左上 OrderForm 下单表单、左下 QuotePanel 行情面板、右上 HoldingsPanel 持仓、右下 TodayOrdersPanel 当日委托/成交。

## 文件清单
| 代码文件 | 作用 |
|----------|------|
| `Trade.vue` | 2×2 网格布局 + 组件间联动（快捷标的、刷新） |
| `OrderForm.vue` | 下单表单：StockCodePicker 选标的、PriceTypeInput 价格类型（numeric 11/5/44）、买卖提交 |
| `QuotePanel.vue` | 实时行情五档/最新价展示（quote store 订阅） |
| `trade/HoldingsPanel.vue` | 持仓列表（承担 /holdings 页职责） |
| `trade/TodayOrdersPanel.vue` | 当日委托/成交双 tab，可撤单（白名单 已报50/部成55） |

## 核心实现

### 布局与联动
```text
(1,1) OrderForm   (1,2) HoldingsPanel
(2,1) QuotePanel  (2,2) TodayOrdersPanel
```
- HoldingsPanel / TodayOrdersPanel 点标的 → `@apply-to-order` → onApplyHolding → quickStock → OrderForm 填入并触发行情订阅
- el-scrollbar 滚动条按需显示（监听 scrollWidth > clientWidth 加 class）

### 下单链路
OrderForm → `orderStore.placeOrder` → POST `/api/orders/place` → 拦截器解包 → order store 内 `_upsertToHoldings`（即 `holdings.applyOrderPush(order, 'open')`）→ 等 ord_cfm 推送刷新状态

### 委托数量快捷按钮 = 可用分数（REQ-FE-543，2026-08-25）

5 个快捷按钮从**绝对股数 `[100, 500, 1000, 5000, 10000]`** 改为**可用数量分数 `[1/10, 1/5, 1/4, 1/2, 1/1]`**：

- 按钮文案只显示分数（如 `1/2`）
- `:title` hover 显示对应股数（如 `"1/2 = 2500 股 (按可用 5000)"`）
- `:disabled="availableTradeQty <= 0"`（无可用时禁用全部 5 个按钮）
- 整手按 `stocksStore.stockTradeUnit(stock_code)` 计算（cache miss 兜底 100）

计算逻辑（`applyFraction(fraction)`）：

| 方向 | available 源 | 取整规则 |
|------|--------------|----------|
| 买入 (order_type=23) | `cash / px`（按价格类型 FIX/LATEST/MARKET_PEER） | 向下 `floor(raw/unit)*unit` |
| 卖出 (order_type=24) | `position.avl_vol` | 向上 `ceil(raw/unit)*unit`，不超 `avl_vol` |

不足 1 手 → `availableTradeQty = 0` → 按钮 disabled（不可下零手）。

`availableTradeQty` computed 抽离自原 `availableText`，单一数据源给分数按钮 + `applyAvailableToVolume`（双击）共用。`availableText` 仅做 toLocaleString 包装。

### 撤单
TodayOrdersPanel 可撤按钮（仅 status 50/55）→ `orderStore.cancelOrder(order_no, trd_date)` → DELETE `/api/orders/{order_no}?trd_date=YYYYMMDD`，本地乐观置 '51' 待撤

### 价格类型
string 'latest'/'market' → numeric PriceType：11（限价）/ 5 / 44（市价，默认），PriceTypeInput 组件统一。
