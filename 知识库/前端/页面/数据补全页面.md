# 数据补全页面

## 对应代码路径

- `client/src/views/HistoryQuoteCompletion.vue`（历史行情补全页）
- `client/src/api/quote_sync.js`（API 客户端）
- `client/src/router/index.js`（路由 `/data-completion/history-quote`）
- `client/src/components/Sidebar.vue`（菜单「数据补全 → 历史行情补全」）

## 功能概述

「数据补全」区下的「历史行情补全」页（admin-only）。主表 = 行情同步任务表（`quote_sync_config`），管理要跟踪并自动补全历史分钟行情的证券，前端驱动按日补全。

- **新增任务**：弹窗填证券代码 + 开始/结束日期（结束默认昨天）→ 后端按 `minute_bars` 已有记录自动定位游标（从最后日期 +1 续补，已落地的不重拉）
- **按日补全**：点「补全」后从 `last_loaded_date+1` 到 `min(end, 昨天)` 逐日调 `POST /api/quote-sync/sync`，串行队列（同一时刻只补一只）
- **状态列**：成功 / 失败 / 同步中 / 未开始（纯 tag，无转圈动画、无失败原因展示——见修改指南）
- **启动自动补全**：`onMounted` 后对 `auto_sync=1` 且未追平的行自动开跑（与后端启动钩子互补，前端是页面驱动路径）

## 核心实现

### 列定义（DataTableView）

| key | label | 说明 |
|-----|-------|------|
| `stock_code` | 证券代码 | `COL.STOCK_CODE` + mono slot |
| `time_range` | 时间区间 | `start_date ~ end_date`（空显示「昨天(开放)」） |
| `last_loaded_date` | 当前已加载到的日期 | mono，空显示「未开始」 |
| `auto_sync` | 自动同步 | `el-switch`（调 `patch`） |
| `status` | 状态 | 纯 tag：成功/失败/同步中/未开始 |
| `action` | 操作 | 补全（串行入队）/ 删除（confirm） |

### 按日循环（runBackfill）

```
cap = end_date ? min(end_date, 昨天) : 昨天
day = next(last_loaded_date || start_date)
while day <= cap:
    r = await quoteSyncApi.syncDay(stock, day)
    r.code === 0 → 更新 row.last_loaded_date/status=success → day = next(day)
    r.code === 1 → row.status=failed, 停止循环 (break)
```

- 串行队列 `_queue = _queue.then(...)`：同一时刻只补一只证券，避免同时压 broker
- 运行态 `rowState[stock] = {busy, day, fail, done}` 存前端（不落库）
- `onMounted` 自动补平 `auto_sync=1` 且 `last_loaded<昨天` 的行

### 新增弹窗

证券代码（正则 `^\d{6}\.(SH|SZ|BJ)$`）+ 开始日期（必填）+ 结束日期（默认昨天，可清空=开放）+ 自动同步开关。保存调 `add`，成功后自动入队补全。

## 修改指南

- **状态列**：当前刻意简化为纯成功/失败 tag（用户 2026-08-30 要求去转圈动画 + 失败原因）。如需恢复转圈/原因展示，加回 `rowState.busy` 的 spin 图标 + `error_msg` tooltip（后端 `quote_sync_config.status/error_msg` 已就绪）
- **失败处理**：`syncDay` 返 `code:1` 时页面停止循环并 `row.status=failed`；失败原因存后端 `error_msg`（当前不展示）
- **新加列**：`quote_sync_config` 加列后，同步改列定义 + 本 spec + data-model spec
- **昨天封顶**：`_yesterday()` 前端算，与后端 `_cap_day` 一致（今天数据不全）
