# 登录与个人中心

## 对应代码路径
- `client/src/views/Login.vue`
- `client/src/views/Profile.vue`
- `client/src/components/ChangePasswordDialog.vue`

## 功能概述
登录页（public，blank 布局）：用户名密码登录、错误提示、redirect 回跳。个人资料页：查看/修改个人资料、修改密码。

## 文件清单
| 代码文件 | 作用 |
|----------|------|
| `Login.vue` | 登录表单 → auth.login → 跳 redirect 或 / |
| `Profile.vue` | 个人资料卡片 + 资料编辑 + 修改密码入口 |
| `ChangePasswordDialog.vue` | 修改密码弹窗（只发新密码，后端不校验旧密码） |

## 核心实现

### Login.vue
- `authStore.login(username, password)` 成功 → `router.replace(route.query.redirect || '/')`
- 已登录访问 /login 由路由守卫直接跳 /
- 失败提示走拦截器 ElMessage（后端 detail）

### Profile.vue
- 资料展示读 `authStore.user`（watch immediate 回填表单）；`authStore.updateProfile(payload)` → saveUser + IDB 同步
- `changePassword`：POST `/auth/change-password` body `{new_password}`（前端 changePassword('', 新密码)，旧密码仅占位不发送，后端不校验）

## 依赖关系
- 上游：auth store、authApi
- 下游：无

## 修改指南
- 登录流程改动注意 auth.login 内三个写入点 + router 守卫联动
- 密码策略如收紧需前后端同步改（server/api/auth.py change-password）
