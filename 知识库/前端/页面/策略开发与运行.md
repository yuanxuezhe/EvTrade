# 策略开发与运行

## 对应代码路径
- `client/src/views/ScriptDev.vue`（脚本开发）
- `client/src/views/ScriptTask.vue`（策略运行，563 行）
- `client/src/api/script_strategy.js`
- `client/src/stores/strategy_helpers.js`

## 功能概述
ScriptDev：Python 策略脚本在线编辑（列表/新建/编辑/公开开关/审计记录）。ScriptTask：策略任务运行台（纯回测、无实盘；创建回测任务、批次管理、实时进度、结果查看；他人公开策略只读精简，无回测/批次入口）。

## 文件清单
| 代码文件 | 作用 |
|----------|------|
| `ScriptDev.vue` | 左侧脚本列表（公开/我的筛选）+ 右侧编辑器 + 可见性开关 + 审计历史 |
| `ScriptTask.vue` | 策略工具栏（标的/公开开关，仅 owner）+ 任务表格 + 详情（进度/回测指标）+ 批次操作（重测守卫：批次无运行中/排队才可） |
| `api/script_strategy.js` | 脚本 CRUD / 任务创建启停 / 状态查询 |
| `strategy_helpers.js` | 列表过滤与状态着色辅助 |

## 核心实现

### ScriptDev 关键点
- **新建脚本**：点击"新建脚本"按钮 → 调 `POST /api/script-strategy/scripts/new` → 后端自动命名 `new_strategy`（重名递增 `new_strategy01`/`02`…）+ 用默认模板创建 → 返回创建结果 → 前端刷新列表并选中。不等用户手动保存。
- 脚本保存走 `POST/PUT /api/script-strategy/scripts`，带版本与审计（strategy_script_audit）
- **可见性开关**：编辑器表单 `el-switch`（公开/私有）绑 `form.is_public`，随保存提交（`_formToPayload` 带 `is_public`）；owner/admin 可改，他人公开脚本只读（`:disabled="isReadonly"`）
- 编辑公开脚本受 owner 限制

### ScriptTask 关键流程
```text
创建回测任务（BacktestForm：script 参数 + 标的 + 回测区间）
  → POST /script-strategy/strategies/{id}/backtest
  → 任务状态经 WS task_progress_update 实时推（ws_dispatch._onTaskProgress → wsStore.lastTaskProgress）
  → 页面：属于当前批次 → 节流刷新任务表格 + 就地更新详情进度/状态
```
- update_strategy 响应不含 script → 保留现有 script（否则 schema 清空回测被挡）
- 重测守卫：批次内无 running/queued 任务才允许

### 进度可视化 + trades 行可展开 + 轮询 fallback（2026-08-29）

- **进度环**：`BatchTasksTable` 行 status=running 时显示 `<el-progress type="circle">` 圆环 + bar/total 文字。进度数据走 `taskProgressMap`（Vue reactive Map<task_id, progress>），ws 推过来时整体替换触发更新。详见 `openspec/specs/frontend/spec.md` REQ-FE-546。
- **trades 行可展开**：`TaskDetail.vue` 交易明细 tab 加 `type="expand"`，展开行按 `stime_side` key 关联 `signal_log` 显示 msg / indicators / state.position / state.cash / trace_id / price_type。列头加 `<el-tooltip :show-after="500">` 说明含义。
- **轮询 fallback**：`_hasActiveTask` computed 监控当前 batch 有 queued/running → 启 3s 周期 `loadBatches + loadBatchTasks`；全 finished/failed 后停。`onBeforeUnmount` 清 timer。

### 回测/实盘引擎
实际执行在独立服务 strategy_exec（Backtrader），见 `知识库/策略服务/`。前端只做任务管理与进度展示。

## 依赖关系
