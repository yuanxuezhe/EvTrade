# 策略开发与运行

## 对应代码路径
- `client/src/views/ScriptDev.vue`（脚本开发）
- `client/src/views/ScriptTask.vue`（策略运行，~48K 行）
- `client/src/api/script_strategy.js`
- `client/src/stores/strategy_helpers.js`

## 功能概述
ScriptDev：Python 策略脚本在线编辑（列表/新建/编辑/公开开关/审计记录）。ScriptTask：策略任务运行台（创建回测/实盘任务、批次管理、实时进度、结果查看）。

## 文件清单
| 代码文件 | 作用 |
|----------|------|
| `ScriptDev.vue` | 左侧脚本列表（v90+ 公开/我的筛选）+ 右侧编辑器 + 审计历史 |
| `ScriptTask.vue` | 策略工具栏（标的/公开开关，仅 owner）+ 任务表格 + 详情（进度/回测指标）+ 批次操作（v124 重测：批次无运行中/排队才可） |
| `api/script_strategy.js` | 脚本 CRUD / 任务创建启停 / 状态查询 |
| `strategy_helpers.js` | 列表过滤与状态着色辅助 |

## 核心实现

### ScriptDev 关键点
- 脚本保存走 `POST/PUT /api/script-strategy/scripts`，带版本与审计（strategy_script_audit）
- 编辑公开脚本受 owner 限制

### ScriptTask 关键流程
```text
创建任务（script_id + 参数 + 回测/实盘模式）
  → 后端转发 strategy_exec 服务 POST /internal/run-task（HTTP）
  → 任务状态经 WS task_progress_update 实时推（ws_dispatch._onTaskProgress → wsStore.lastTaskProgress）
  → 页面：属于当前批次 → 节流刷新任务表格 + 就地更新详情进度/状态
```
- update_strategy 响应不含 script → 保留现有 script（否则 schema 清空回测被挡）
- v124 重测守卫：批次内无 running/queued 任务才允许

### 回测/实盘引擎
实际执行在独立服务 strategy_exec（Backtrader），见 `知识库/策略服务/`。前端只做任务管理与进度展示。

## 依赖关系
- 上游：scriptStrategyApi、ws store（lastTaskProgress）、holdings（策略委托展示）
- 下游：无；后端 `server/api/script_strategy/` 转发
