# 系统管理

## 模块名
用户管理（Users）+ 系统初始化（SystemInit）+ 系统配置（SystemConfig）+ 证券信息设置（AdminStockConfig）

## 对应代码路径
- `client/src/views/Users.vue`、`SystemInit.vue`、`SystemConfig.vue`、`AdminStockConfig.vue`
- `client/src/components/users/UserEditDialog.vue`、`UserResetPwdDialog.vue`
- `client/src/composables/useUserActions.js`
- `client/src/api/admin.js`、`api/sync.js`、`api/sysconfig.js`

## 功能概述
管理员工具集：用户 CRUD 与启停/重置密码；交易日初始化（day-init）流程与对账报告；系统配置项（sysconfig）查看编辑（普通用户可看，写权限 admin）；证券信息管理页（分页编辑表，原爬虫同步页已删）。

## 核心实现

### Users.vue + useUserActions
- 列表列：username/full_name/role 徽章（admin 管理员/trader 交易员/viewer 只读）/email/is_active switch/操作
- edit 段（useUserActions）：openCreate/openEdit/submitEdit；rules：username `/^[A-Za-z0-9_\-.]{3,32}$/`、password min6、email 正则、role 必填
- pwd 段：new_password + confirm 一致性校验
- toggleActive：ElMessageBox 确认 → userApi.update(id, {is_active: !})；confirmDelete：确认 → userApi.delete(id)
- Dialog defineExpose({formRef, validate})，父级 submit 前 await validate()

### SystemInit.vue
- 触发后端 day-init：`sysStatusApi.init(trdDate, mode)`（POST /admin/sys-status/init）→ init_start → initializing gate（holdings.initializing=true，ws_dispatch 丢弃洪峰推送）→ init_completed/aborted
- 页面还展示对账报告列表（reconcileApi.listReports / getReport）；manual 模式走 `sysStatusApi.init(date, 'manual')`
- 完成 → holdings.resetForNewDay()（切交易日 force re-bootstrap，2026-07-21-system-init-page-refresh；ws 推送丢失时 handleInit 内双保险直调）
- 失败 aborted 展示错误；stuck gate 由 bootstrap 兜底清理

### SystemConfig.vue
- sysconfig 键值列表（如 confirm_before_order 等），admin 可编辑保存，普通用户只读
- 写后注意 60s 内存缓存延迟（order store _confirmCache）

### AdminStockConfig.vue
- 证券信息管理：stocks store `fetchPage`（后端真分页 + keyword/sector 子串/is_t0_able/stktype 筛选，板块为子串匹配）+ DataTableView 表格
- 行内编辑 stocksApi.update、新建 stocksApi.create；「同步缓存」按钮调 store.refreshCache（拉 /stocks/all 全量重建 IDB）
原 AdminSync 独立页已删；当前页面已无爬虫启停/进度 UI，sync store 仍存在但仅由 ws_dispatch 驱动、无视图消费

## 依赖关系
- api：userApi（users CRUD/reset-password，api/index.js）、adminApi（sysStatusApi/reconcileApi/sessionApi/feeConfigApi）、sysconfigApi、stocksApi
- stores：holdings（initializing/resetForNewDay）、stocks（分页/编辑）、auth（isAdmin 判断写权限）
- 与后端日初协议耦合：init_start / init_completed / init_aborted 三事件

## 修改指南
- **用户字段/校验**：UserEditDialog + useUserActions editRules 两处同步；与 Login/ChangePasswordDialog 密码下限一致
- **sysconfig 新键**：后端注册默认值 + SystemConfig 自动展示；消费方读值注意失败默认 false
- **日初流程改动**：initializing gate 与 resetForNewDay 时序不可拆（防中间态数据上屏）
- **同步管理**：进度一律走 sync store + WS 推送，勿另起轮询
