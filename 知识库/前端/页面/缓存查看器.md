# 缓存查看器（Cache 四页）

## 对应代码路径
- `client/src/views/CacheAsset.vue`、`CachePositions.vue`、`CacheOrders.vue`、`CacheTrades.vue`（均 admin）
- `client/src/components/CacheTableView.vue`
- `client/src/components/DataTableView.vue`
- `client/src/utils/idb.js`、`utils/tableColumns.js`、`utils/trdDateFilter.js`

## 功能概述
admin-only 的前端 IndexedDB 四张业务表（asset/positions/orders/trades）CRUD 查看器：查看本地缓存原始数据、按交易日过滤、清理缓存，用于排查"前端显示与后端不一致"问题。

## 文件清单
| 代码文件 | 作用 |
|----------|------|
| `CacheAsset.vue` | IDB asset 表查看 |
| `CachePositions.vue` | IDB positions 表查看 |
| `CacheOrders.vue` | IDB orders 表查看 |
| `CacheTrades.vue` | IDB trades 表查看 |
| `CacheTableView.vue` | 缓存表通用容器（加载/过滤/清空操作栏） |
| `DataTableView.vue` | 通用数据表格（列配置 tableColumns.js、排序/分页） |

## 核心实现

### 数据来源
- 直接读浏览器 IndexedDB（utils/idb.js），不经后端 API
- trdDateFilter.js 提供按 trd_date 过滤

### 用途定位
- v113 后 orders 启动拉全量缓存（all=true），本查看器是核对缓存与 DB 差异的诊断工具
- 清空操作只影响本机浏览器缓存，不动后端

## 依赖关系
- 上游：utils/idb.js
- 下游：无

## 修改指南
- 新增业务表缓存时同步加对应 Cache 页 + 路由（requiresAdmin）
- 列展示改 tableColumns.js，勿在各页重复定义
