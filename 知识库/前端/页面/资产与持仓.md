# 资产与持仓

## 对应代码路径
- `client/src/views/Asset.vue`
- `client/src/views/Position.vue`
- `client/src/components/PositionTable.vue`、`PositionDetail.vue`

## 功能概述
资产页：总资产横幅 + 资金明细卡片（现金/可用/冻结/市值/期初）。持仓页：持仓列表（旧独立页，现主要经 Trade 页 HoldingsPanel 呈现）。

## 文件清单
| 代码文件 | 作用 |
|----------|------|
| `Asset.vue` | 总资产横幅 + 资金详情卡片 |
| `Position.vue` | 持仓列表（路由 /positions 已 redirect 到 /t0-trade，页面保留） |
| `PositionTable.vue` | 持仓表格通用组件（列含实时市值/盈亏/收益率） |
| `PositionDetail.vue` | 持仓明细（含 admin 调平入口 adjustPosition） |

## 核心实现

### Asset.vue 数据源
- holdings.cachedAsset（v99 后由 5s asset_update WS 推送持续覆盖 + REST 兜底）
- last_asset = 期初资产（v114 锁定，日初写入）

### 持仓实时市值
- PositionTable 每行市值 = vol × quote store 实时价（getMarketValue/getProfit/getReturnRate computed）
- 行情缺失时显示成本价计算的静态值

### admin 调平（v12）
PositionDetail → `api.adjustPosition(stockCode, {deltaVol, deltaAvlVol, reason})`（PUT）→ holdings 刷新；`adjustAsset`（PUT /asset/adjust）同理。reason 仅记 log 不入库。

## 依赖关系
- 上游：holdings/quote store、api（asset 调平）
- 下游：无

## 修改指南
- 资金字段展示改动需与 assets 表字段、asset_update WS payload 三处对齐
- last_asset 语义（期初锁定）勿当成"昨日总资产"误用
