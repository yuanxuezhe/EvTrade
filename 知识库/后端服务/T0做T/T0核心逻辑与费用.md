# T0 核心逻辑与费用

## 对应代码路径

- `server/services/t0/core.py` — 整手/数量/费用计算
- `server/services/t0/fees.py` — 精确费用（Decimal）
- `server/services/t0/pnl.py` — 已实现盈亏

## 功能概述

T0 做T的纯计算层（无 DB、无 IO），三个模块全部是纯函数。core.py 提供整手取整（LOT_SIZE=100）与净额计算；fees.py 用 Decimal ROUND_HALF_UP 精确计算佣金/印花税（含最低佣金兜底）；pnl.py 计算已实现盈亏。

```python
def calc_commission_and_tax(order_type, price, volume, fee_cfg):
    """
    佣金 = max(金额 * 佣金率, min_commission)   # 最低佣金兜底
    印花税 = 卖出金额 * 税率（仅 SELL 收）
    过户费 = 金额 * 过户费率（双向）
    返回 (commission, stamp_tax, total_fee)
    """
```

- 必须用 Decimal：float 二进制误差在 4000+ 笔累计后会显式偏离柜台对账单。
- fee_cfg 来自配置（佣金率/最低佣金/印花税率/过户费率），费率调整只改配置不改代码。

### 已实现盈亏（pnl.py）

```python
def calc_realized_pnl(sell_trades, cost_basis, fee_cfg):
    """
    realized = (avg_sell - cost_basis) * sell_vol - commission - stamp_tax
    返回 (realized, commission, stamp_tax)
    """
```

- `cost_basis`：底仓成本价（positions.cost_price）。
- `avg_sell`：当日卖出成交均价（按成交量加权）。
- 浮动盈亏不在此模块（在 t0_stats 装配层，用现价替代无卖单时的 avg_sell）。

## 修改指南

- **费率调整**：只改 fee_cfg 配置项；`calc_commission_and_tax` 的公式（min_commission 兜底、印花税仅卖出）是券商契约。
- **精度**：所有金额计算走 `_q2`；禁止在新增逻辑中直接用 float 运算后回写 Decimal 字段。
- **整手规则**：A 股 100 股整手是交易所规则，科创板/北交所特殊整手（200 股起 1 股递增）如需支持，改 `round_to_lot` 时按板块分流而不是加全局参数。
- **纯函数约束**：本层不要引入 tables/settings 导入，保持可独立单测；需要配置的通过参数 fee_cfg 注入。
