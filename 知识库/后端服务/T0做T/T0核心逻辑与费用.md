# T0 核心逻辑与费用

## 对应代码路径

- `server/services/t0/core.py` — 整手/数量/费用计算
- `server/services/t0/fees.py` — 精确费用（Decimal）
- `server/services/t0/pnl.py` — 已实现盈亏

## 功能概述

T0 做T的计算层。core.py 提供整手取整（LOT_SIZE=100）、配平量与净额计算，并含 `get_fee_config`（读 sysconfig 费率配置，非纯函数）；fees.py 提供 Decimal ROUND_HALF_UP 精确量化工具（`_q2`/`_q4`）与佣金/印花税计算（float round + min_commission 兜底）；pnl.py 计算已实现盈亏（纯函数）。

## 文件清单

| 文件 | 核心函数 |
|---|---|
| `server/services/t0/core.py` | `round_to_lot`, `calc_t0_volume`, `calc_commission`, `calc_net_amount`, `get_fee_config` |
| `server/services/t0/fees.py` | `_q2`, `_q4`, `calc_commission_and_tax`（+ 常量 `_BUY_TYPE=23 / _SELL_TYPE=24 / _FAILED_STATUS=55`） |
| `server/services/t0/pnl.py` | `calc_realized_pnl` |

## 核心实现

### 整手算法（core.py）

```python
LOT_SIZE = 100

def round_to_lot(volume: int, direction) -> int:
    """BUY 向下取整到 100 股（防资金不足废单）
       SELL 向上取整到 100 股（清仓优先）"""
```

- `calc_t0_volume(target_volume, coefficient, direction)`：目标股数 × 系数 → int 截断 → 过整手。
- `calc_net_amount(price, volume, cfg, direction)`：净收付金额（买含佣金；卖扣佣金+印花税），返回 `(gross, net)`。
- `calc_commission(amount, cfg, direction)`：float 口径佣金+印花税（不带 min_commission 兜底，兜底在 fees.calc_commission_and_tax）。
- `get_fee_config()`：读 sysconfig 费率（commission_rate 默认 0.0001 / stamp_tax_rate 默认 0 / min_commission 默认 0 免五 / slippage 默认 0.001）。

### 费用计算（fees.py）

```python
def _q2(x) -> float   # Decimal(str(x)).quantize(0.01, ROUND_HALF_UP)，金融 2 位
def _q4(x) -> float   # 同上 4 位（胜率/收益率）

def calc_commission_and_tax(amount, fee_cfg, direction):
    """
    佣金 = max(金额 * 佣金率, min_commission)   # 最低佣金兜底（当前免五 min=0 自动跳过）
    印花税 = 卖出金额 * 税率（仅 SELL 收；当前税率 0 恒为 0）
    返回 (commission, stamp_tax)
    """
```

- 必须用 Decimal：float 二进制误差在 4000+ 笔累计后会显式偏离柜台对账单。
- fee_cfg 来自配置（佣金率/最低佣金/印花税率/过户费率），费率调整只改配置不改代码。

### 已实现盈亏（pnl.py）

```python
def calc_realized_pnl(sell_trades, cost_basis, fee_cfg):
    """
    realized = (avg_sell - cost_basis) * sell_vol - commission - stamp_tax
    返回 (realized, commission, stamp_tax)
    """
```

- `cost_basis`：底仓成本价（positions.cost_price）。
- `avg_sell`：当日卖出成交均价（按成交量加权）。
- 浮动盈亏不在此模块（在 t0_stats 装配层；当日无卖出时保守返回 0，前端用行情现价）。

## 修改指南

- **费率调整**：只改 fee_cfg 配置项；`calc_commission_and_tax` 的公式（min_commission 兜底、印花税仅卖出）是券商契约。
- **精度**：所有金额计算走 `_q2`；禁止在新增逻辑中直接用 float 运算后回写 Decimal 字段。
- **整手规则**：A 股 100 股整手是交易所规则，科创板/北交所特殊整手（200 股起 1 股递增）如需支持，改 `round_to_lot` 时按板块分流而不是加全局参数。
- **纯函数约束**：本层不要引入 tables/settings 导入，保持可独立单测；需要配置的通过参数 fee_cfg 注入。
