# T0 统计与聚合

## 对应代码路径

- `server/api/t0_stats.py` — 单股票 T0 统计端点
- `server/api/t0_aggregate.py` — 敞口/聚合端点
- `server/services/t0/aggregators.py` — 聚合算法核心
- `server/services/t0/aggregate_api.py` — facade 再导出
- `server/services/t0/tasks.py` — `_prefetch_task_stats`（批量预取）

## 功能概述

T0 做T的统计视图层：按股票统计当日做T盈亏（已实现/浮动）、净敞口、聚合汇总（按股票/按天/总览）。所有口径基于当日 orders（strategy_type=1/挂 task_id 的做T单），排除 `CANCEL:` 撤单行（v130.2 防撤单虚增 day_pnl）。

## 文件清单

| 端点 | 说明 |
|---|---|
| GET /api/orders/t0-stats/{stock_code} | 单股票当日 T0 统计（T0StatsOut 15 字段） |
| GET /api/orders/t0-history/{stock_code} | 单股票 T0 历史日序列 |
| GET /api/orders/t0-exposure | 当前净敞口（T0ExposureOut） |
| GET /api/orders/t0-aggregate | 聚合汇总（T0AggregateOut） |

## 核心实现

### T0StatsOut（15 字段，t0_stats.py）

关键字段口径：

| 字段 | 计算式 |
|---|---|
| buy_volume / sell_volume | 当日做T买/卖委托量（撤单行已排除） |
| buy_amount / sell_amount | 对应金额 |
| net_volume / net_amount | 买卖净差额（敞口） |
| day_pnl | `(avg_sell - cost_basis) * sell_vol - commission - stamp_tax`（已实现） |
| unrealized_pnl | `(avg_sell - cost_basis) * position_vol`（浮动，avg_sell 无卖单时用现价） |
| commission / stamp_tax | 见 T0核心逻辑与费用.md |

### aggregators.py 核心函数

```
apply_user_def_filter(rows)   v130.2: 排除 user_def 以 'CANCEL:' 开头的行
calc_net_exposure(orders)     净敞口 = Σ卖量 - Σ买量（股）
aggregate_by_stock(rows)      按股票分组 → {stock_code: 统计}
aggregate_by_day(rows)        按天分组 → 日序列
aggregate_summary(rows)       总览（总买卖额/总费用/总盈亏）
resolve_t0_user_defs(...)     从 orders 行提取做T归因信息
```

### aggregate_api.py

纯 facade：`from .aggregators import *` 再导出，供 api 层与旧调用方稳定引用。改动 aggregators 函数签名时无需改 api 层 import。

### 数据装配模式（性能关键）

- 单股票统计：`Orders.query_by('trd_date', trd_date)` → 内存过滤 stock_code + strategy_type + task_id。
- 敞口/聚合多股票：先取 active T0 任务集，再 `Orders.query_by_in('task_id', task_ids)` 一次批量拉回（v127.2），内存分组聚合。

## 修改指南

- **口径变更**：day_pnl/unrealized 的计算式集中在 pnl.py + t0_stats.py 装配处，改口径两处同步；不要在 aggregators 里重复实现盈亏公式。
- **新统计维度**：加在 aggregators 的 aggregate_* 函数并保持纯函数（输入 rows 输出 dict），端点层只做取数与 schema 装配。
- **过滤规则**：`apply_user_def_filter` 是所有统计的入口过滤器，任何新统计端点必须先过它。
- **性能红线**：禁止在循环内逐股票 `query_by`；多股票场景一律 query_by_in 批量取。
