# 入口与生命周期

## 对应代码路径

- `server/main.py`
- `server/lifecycle/__init__.py`、`server/lifecycle/seed.py`
- `server/services/sysconfig`、`server/services/strategy/quote_consumer.py`、`server/services/strategy/signal_consumer.py`
- `server/cache/quote_cache_flusher.py`、`server/auth/session.py`、`server/services/rpc_health.py`

## 功能概述

main.py 是 FastAPI app 入口（phase-2 拆分后只负责装配）：CORS 配置、root logger 初始化与文件日志、请求日志中间件、WebSocket 端点注册、6 组 startup / shutdown hooks（DB seed、sysconfig 预载、RPC 客户端、行情消费者、quote cache flusher、signal consumer、auth session sweep），以及 public / protected / admin 三组路由注册。pytest 模式下跳过所有外部连接类 hook。

## 文件清单
| 代码文件 | 作用 |
|----------|------|
| server/main.py | app 入口：装配 hooks + 路由 + 中间件 |
| server/lifecycle/seed.py | init_and_seed()：validate_config → init_db 建表 → 跑 pending migrations → seed 默认账号 |
| server/lifecycle/__init__.py | 导出 init_and_seed |
| server/services/rpc_health.py | RPC 连上后启动资金定时同步 + 健康监测（start_sync/stop_sync） |
| server/services/strategy/quote_consumer.py | QuoteConsumer：7×24 行情消费（get_quote_consumer/close_quote_consumer） |
| server/services/strategy/signal_consumer.py | 订阅 strategy.exchange 收 signal → POST /api/orders/place |
| server/cache/quote_cache_flusher.py | 内存行情快照 → MySQL 周期 flush 后台 task |
| server/auth/session.py | token session cache；sweep_loop 每 60s 清理 idle 过期 token |

## 核心实现

### 模块加载阶段（import 时即执行）
1. 清空 uvicorn 挂的 root handlers → `logging.basicConfig(level=INFO, format="%(message)s")`（REQ-LOG-005，让 `[front->svc]` 等自定义 logger 可见；时间戳/level 前缀由 logflow 自带）。
2. `setup_file_logging()`（REQ-LOG-006）：日志落地 `logs/server-YYYYMMDD.log`，保留 7 天。
3. `logging.getLogger("uvicorn.access").disabled = True`（被 RequestLoggingMiddleware 替代）。

### CORS
- 环境变量 `EVTRADE_CORS_ORIGINS`（逗号分隔），默认
  `http://localhost:50998,http://localhost:3000,file://,null`
  （vite dev / 客户端生产构建 / file:// 本地 demo / null origin）。
- `allow_credentials=True, allow_methods=["*"], allow_headers=["*"]`。

### 中间件与 WS 注册
- `app.add_middleware(RequestLoggingMiddleware)`：跳过 `/api/health`、`/ws/*`。
- `register_ws_endpoint(app)`：必须在 startup 之前调用（内部用装饰器注册 `/ws/{channel}`）。

### startup hooks（按注册顺序）

| hook | 作用 | pytest 跳过 |
|------|------|-------------|
| on_startup_register_loop | v91.4：把 main event loop 写入 `ws_manager._main_loop`，让 sync 线程能 schedule broadcast | 否 |
| on_startup | `init_and_seed()`（建表+migrations+默认账号 admin/admin123、trader/trader123）；`sysconfig.load_all()` 一次性加载配置缓存；stale task 清理已移交 strategy_exec 服务，此处仅占位 | 否 |
| on_startup_rpc | `get_rpc_client()` 连 RabbitMQ（reply+push 监听）；成功后 `rpc_health.start_sync()` 资金定时同步 | 是（PYTEST_CURRENT_TEST） |
| on_startup_quote_consumer | `get_quote_consumer()` 无条件启动（行情 7×24 必需，与策略引擎解耦） | 是 |
| on_startup_quote_cache_flusher | `start_quote_cache_flusher()`：每 `QUOTE_CACHE_FLUSH_INTERVAL`（默认 60s）把内存 quote_cache 批量回写 MySQL | 是 |
| on_startup_signal_consumer | v120+ strategy_exec_service：订阅 signal → 自动下单（失败 non-fatal） | 否（内部自守护） |
| on_startup_auth_sweep | REQ-AUTH-IDLE-001：`sweep_loop()` 协程每 60s 清理 10min idle 过期 token；后端重启 cache 清零 → 所有 token 失效 | 是 |

### shutdown hooks
- rpc_health `stop_sync()` → `close_rpc_client()`
- `close_quote_consumer()` → cancel quote cache flusher task（finally 内做最后 flush）
- `stop_signal_consumer()`
- cancel auth sweep task

### 路由注册

- **public**（无鉴权）：`/api/auth`、`/api/trading`（clock）
- **protected**（`Depends(get_current_user)`）：`/api/positions`、`/api/holdings`、`/api/orders`（orders + t0_stats + t0_aggregate 共用前缀）、`/api/t0-tasks`、`/api/sysconfig`、`/api/trades`、`/api/asset`、`/api/fee-config`、`/api/system`、`/api/script-strategy`、`/api/quote`、`/api/stocks`、`/api/sync`
- **admin**（登录 + handler 内 role 检查）：`/api/users`、`/api/admin/sys-status`、`/api/admin/reconcile`、`/api/admin/trading-session`
- `/api/health`：无鉴权探活（evctl.py / k8s probe）；前端 keepalive 用 `/api/auth/heartbeat`。

### pytest 模式
`os.environ.get("PYTEST_CURRENT_TEST")` 存在时跳过 RPC / quote consumer / cache flusher / auth sweep，避免 TestClient 连真 RabbitMQ 与行情源。

## 依赖关系
- 上游：uvicorn 启动器、前端
- 下游：lifecycle/seed → infra.db + migrations；rpc → RabbitMQ；quote_consumer → hqserver WS；flusher → quote_cache + repo

## 修改指南
- 新增 startup 后台任务：仿照 auth sweep 模式（模块级 task 变量 + startup ensure_future + shutdown cancel），外部连接类必须加 PYTEST_CURRENT_TEST 跳过。
- 新增路由：protected 组用 `_AUTH` 依赖；admin 组在 handler 内查 role（不要只依赖 JWT claims 缓存）。
- 勿在 main.py 写业务；seed 逻辑只改 lifecycle/seed.py。
