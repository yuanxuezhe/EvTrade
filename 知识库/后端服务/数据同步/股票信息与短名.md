## 功能概述

- **股票基础信息 CRUD**：
  - `GET /api/stocks` — 真分页（page/page_size，1..500），服务端筛选 sector（子串不区分大小写）/keyword（code+name+short_name 包含）/is_t0_able/stktype
  - `GET /api/stocks/all` — 全量不分页（前端 IndexedDB 首次缓存/同步刷新用）
  - `GET /api/stocks/{stock_code}` — 单只详情
  - `PATCH /api/stocks/{stock_code}` — admin 编辑（8 字段白名单，`extra=forbid`）
  - `POST /api/stocks` — admin 手动添加（stock_code 正则校验）
- **短名生成**（REQ-STOCK-007）：`to_short_name(stock_name)` — 汉字拼音首字母 + ASCII run 整串保留 + ST 前缀保留 + 16 字符上限；stock_name 变更时自动重算，**API 不接受 short_name 直填**
- **爬虫数据源**：
  - sina_list：拉全市场 ~5529 只 A 股代码（56 页×100/页），24h TTL 本地缓存
  - eastmoney：按代码逐只拉基本面（stock_name + sector 申万二级）

## 核心实现

### 1. 短名算法（services/short_name.py）

```python
from pypinyin import lazy_pinyin

def to_short_name(stock_name: Optional[str]) -> str:
    if not stock_name: return ""
    name = stock_name.strip()
    # 1) ST 前缀检测（大小写不敏感）: *st/*ST → prefix="*ST"; st/ST → prefix="ST"
    if name.lower().startswith("*st"): prefix = "*ST"; name = name[3:].strip()
    elif name.lower().startswith("st"): prefix = "ST";  name = name[2:].strip()
    # 2) re.split 分离 ASCII run:
    #    ASCII 串(ETF/50ETF/300) 整串保留大写; 其余 token 走 lazy_pinyin 取每段首字母
    parts = []
    for token in re.split(r"([A-Za-z0-9]+)", name):
        if not token: continue
        if re.fullmatch(r"[A-Za-z0-9]+", token):
            parts.append(token.upper())
        else:
            parts.append("".join(s[0] for s in lazy_pinyin(token) if s).upper())
    return (prefix + "".join(parts))[:16]     # 3) 16 字符上限; 异常 fallback ""
```

示例：`平安银行→PAYH`、`创业板ETF→CYBETF`、`华夏上证50ETF→HXSZ50ETF`、`京东方A→JDA`、`*ST实达→*STSD`、`*st康佳→*STKJ`。

**实现要点**：不可对 lazy_pinyin 每段取 s[0]（pypinyin 会把连续 ASCII 串（ETF/50ETF）当一个段 → 只剩首字符（E/5）），改用 `re.split(r"([A-Za-z0-9]+)", ...)` 整串保留。

### 2. 列表端点（真分页 + 筛选）

```python
@router.get("")
async def list_stocks(sector=None, keyword=None, is_t0_able=None, stktype=None,
                      page: int = 1, page_size: int = 100, limit: Optional[int] = None, db=Depends(get_db)):
    if page < 1: raise HTTPException(400, "page must be >= 1")
    if page_size < 1 or page_size > 500: raise HTTPException(400, "page_size must be in 1..500")

    rows = Stocks.query_all()                          # 全表后内存筛选（~5500 行可接受）
    if sector:    rows = [r for r in rows if sector.lower() in (r.sector or '').lower()]   # 子串匹配
    if is_t0_able is not None: rows = [r for r in rows if bool(r.is_t0_able) == is_t0_able]
    if stktype is not None:    rows = [r for r in rows if r.stktype == stktype]
    if keyword:   rows = [r for r in rows if kw in r.stock_code.lower()
                          or kw in (r.stock_name or "").lower()
                          or kw in (r.short_name or "").lower()]
    total = len(rows)                                  # total 与分页无关
    if limit is not None:                              # 老客户端兼容: limit 优先, 不分页
        rows = sorted(rows, key=lambda r: r.stock_code)[:limit]
        return {"code": 0, "msg": "ok", "list": [...], "total": total}
    offset = (page - 1) * page_size                    # 真分页: 按 stock_code 排序后切片
    return {"code": 0, "msg": "ok", "list": [...], "total": total, "page": page, "page_size": page_size}
```

### 4. Eastmoney 基本面适配（crawler/sources/eastmoney.py）

```python
_PAGE_AJAX_URL = "https://emweb.securities.eastmoney.com/PC_HSF10/CompanySurvey/PageAjax"
_DEFAULT_HEADERS = {"User-Agent": "Mozilla/5.0 ... Chrome/120", "Referer": ".../CompanySurvey/Index", ...}

def _format_code(stock_code):        # '000001.SZ' → 'SZ000001'（{market}{code} 不带点）
    parts = stock_code.rsplit(".", 1)
    return f"{parts[1]}{parts[0]}" if len(parts) == 2 else stock_code

def fetch_base_info(stock_code, timeout=10.0) -> Optional[Dict]:
    resp = requests.get(_PAGE_AJAX_URL, params={"code": _format_code(stock_code)},
                        headers=_DEFAULT_HEADERS, timeout=timeout)
    jbzl = resp.json().get("jbzl", [])[0]            # 基本资料
    return {"stock_code": stock_code,
            "stock_name": jbzl.get("SECURITY_NAME_ABBR") or "",
            "sector": _extract_sector(jbzl.get("INDUSTRYCSRC2"))}   # 申万二级直接入 sector
    # 网络/解析失败一律 return None（打日志），不抛
```

### 5. Sina 全市场代码列表（crawler/sources/sina_list.py）

```python
SINA_HQ_URL = "https://vip.stock.finance.sina.com.cn/quotes_service/api/json_v2.php/Market_Center.getHQNodeData"

def fetch_all_a_codes(use_cache=True, cache_dir="data", cache_ttl_hours=24) -> List[str]:
    cached = _read_cache(cache_dir, ttl_hours)          # 命中直接返（<100ms）
    if cached is not None: return cached
    raw_list = _fetch_all_pages()                        # 56 页 × ~0.3s ≈ 17s

```

```python
def _fetch_all_pages():                 # 分页直到返空 / 不满一页 / page>100 防呆
    while True:
        rows = _fetch_one_page(page)    # URL: ?node=hs_a&page=N&num=100&sort=symbol&asc=1
        if not rows or len(rows) < SINA_HQ_PAGE_SIZE: break
        page += 1; time.sleep(PAGE_FETCH_INTERVAL_SEC)

def _symbol_to_evtrade(sina_symbol):    # 'sh600519' → '600519.SH'; 'bj920169' → '920169.BJ'
    market = symbol[:2].upper(); code = symbol[2:8]
    if market not in ("SH", "SZ", "BJ"): raise ValueError(...)
    return f"{code}.{market}"
```

失败策略：**禁止 silent fallback**——网络失败/JSON 解析失败/缓存损坏一律抛 RuntimeError，由调用方决定（api/sync.py 转 500）。缓存 schema：`{"fetched_at": ISO, "source", "count", "codes": [...]}`，fetched_at 超过 TTL 返 None 触发重拉。
