# 数据表清单

## 对应代码路径

- `server/tables/*.py`（每表一个 TableBase 子类）
- `server/schema.yml`（schema 单一事实来源：pk/columns/indexes/comment）

## 功能概述

全部 21 张表的一句话说明 + 主键 + 关键字段。表类由 scripts/gen_tables.py 从 schema.yml/DB 自动生成；字段完整定义看 schema.yml，本清单用于快速定位。

## 核心实现

### 表明细（主键 / 关键字段 / 索引）

| 表 | 主键 | 一句话说明 + 关键字段 |
|----|------|----------------------|
| orders | (trd_date, order_no) | 委托主表。order_id 柜台号（ord_cfm 到达填入）、stock_code、order_type('23'买/'24'卖)、price_type(0限价/1最新/2市价)、price/volume/traded_volume/traded_amount/avg_price、cancelled_volume、order_flag(0普通/1撤单行)、status('48'未报…'57'废单)、status_msg、order_time(23字符)、raw_id(撤单行=原order_no)、task_id(关联 t0_tasks)、strategy_type(0普通/1快速做T)、user_def(透传备注，CANCEL: 前缀标记撤单)、pushed_at；索引 trd+status/task_id/stock/order_id/user_def/strategy_type |
| trades | (trd_date, order_no, trade_id) | 成交回报。stock_code、price/volume/amount、trade_time、trade_type；索引 order_no、trd_date+stock_code |
| positions | (stock_code) | 持仓（以 broker pos_push 覆盖式同步为唯一数据源）。stock_name、last_vol/avl_vol/vol、cost_price、synced_at/synced_from |
| assets | (id) | 资金单行表（id=1）。cash、available、frozen_cash、market_value、total_asset、last_asset、synced_at/synced_from |
| minute_bars | (stock_code, stime) | 历史分钟 K 线（broker his_hq 1m）。stime(14位 YYYYMMDDHHMMSS)、open/close/high/low、avg_price(=VWAP amount/(volume*100) 元/股)、volume(手)；写入 ON DUPLICATE KEY UPDATE 幂等 |
| quote_sync_config | (stock_code) | 行情同步任务表/配置（要跟踪并自动补全的证券）。start_date/end_date(空=开放到昨天)、last_loaded_date(续传游标)、auto_sync(1/0) |
| stocks | (stock_code) | 证券基础信息（爬虫同步）。stock_name、short_name、sector、is_t0_able、min_buy_qty、trade_unit、stktype(0股票/1ETF)、scale(价格小数位) |
| stkpool | (id, 自增) | 证券池主表（add-stkpool-module）。name、remark、created_at |
| stkpooldetail | (id, stock_code) | 证券池明细。共享主表 id + stock_code 复合 PK；索引 id |
| users | (id)（schema.yml pk 为空，实际 ORM 有 PK） | 用户。username 唯一、password_hash、role(admin/trader/viewer)、is_active、must_change_password、last_login_at |
| sys_config | (user, cfg_key) | 统一配置 KV（user='0' 默认区 / 'system'）。cfg_val、desc、updated_by；启动 load_all 进内存 cache |
| sys_status | (id) | 系统状态单行表（id=1，CHECK 单行）。trd_date 当前交易日、status、is_half_day、initialized_at/by、closed_at/by、remark |
| order_no_seq | (seq_name) | 本地委托号多发生器（multi-generator）。last_value、updated_at；按 seq_name 区分生成器 |
| quote_snapshots | (id, 自增) | 行情快照（最新价+五档买卖盘共 22 字段）。stock_code、last_price、open/high/low/prev_close、volume、amount、bid1-5_price/vol、ask1-5_price/vol、ts；索引 ts、stock_code+ts（唯一约束保证每股一行） |
| reconcile_report | (trd_date, mode, created_at) | 对账报告。diffs_json、broker/local_asset_json、broker/local_positions_json、rpc_status、error_message、created_by；LargeText 列 |
| strategy_script | (user_id, id) | 用户 Python 脚本策略。name、code(LargeText)、params_schema(JSON)、description、status(active)、is_public |
| strategy_script_audit | (id, BIGINT 自增) | 策略执行审计。task_id、stime、trd_date、phase、trigger_type、stock_code、price/volume、indicators/state/payload(JSON)、msg、order_no；索引 task+created_at、task+trd_date |
| strategy_task | (id, 自增) | 回测/实盘任务运行态。user_id、stock_code、mode、status(pending…)、params/backtest_result/positions/progress/live_signals(JSON 大列——列表查询用 columns 白名单跳过)、pnl、trades_count、backtest_start/end_date、period、metric+backtest_metric_value、strategy_id、batch_no、version、execution_service('evtrade')、execution_pid、started_at/finished_at/error_msg/description；索引 user+status、mode、strategy+batch+status |
| strategy | (strategy_id, 自增) | 策略定义。user_id、script_id、name、status('draft')、is_public、stock_code(绑定标的)、best_params(JSON)、t0_params(JSON) |
| strategy_order | (id, 自增) | 策略下单母单：可重复启停，子单按 parent_task_id 归因。task_id、user_id、strategy_id、stock_code、status('stopped')、active_task_id、run_count、last_started/stopped_at、closed_at |
| t0_tasks | (id, 自增) | 快速做T任务。user_id、stock_code、base_volume/target_volume/coefficient、status、note、created_trd_date、closed_at；索引 user+status、status+created_at、stock_code |
| token_sessions | (token_hash) | REQ-AUTH-IDLE-001 token session cache（跨 worker 共享、重启即清空）。user_id、role、created_at、last_seen_at；索引 user_id、last_seen_at |
| _applied_migrations | (name) | lifecycle/seed 自动跑 server/migrations/ 的执行记录。applied_at |

### 命名约定
- 日期字段 `trd_date` 为 8 位数字字符串（'20260722'）；含 trd_date 的表 trd_date 必入主键。
- 单行表（assets/sys_status）按 id=1 约定访问。
- JSON/LargeText 大列查询时用 `query_by_fields(columns=[...])` 白名单规避。

## 依赖关系
- 上游：api/services 层（唯一数据入口）；scripts/gen_tables.py 生成
- 下游：MySQL（EVTRADE_DB_URL）；schema.yml ↔ tables/*.py ↔ alembic 联动

## 修改指南
- 改字段流程：编辑 `server/schema.yml` → `python scripts/sync_schema.py diff` 预览 → `apply`（生成 ORM → Alembic migration → 执行 → 重生成 tables）。
- 生成文件（`__init__.py`、各表 .py 头部标注"自动生成"）不要手改，会被下次生成覆盖。
- 新表记得在业务侧统一走 TableBase 方法；索引变更同步写进 schema.yml 的 indexes 段。
