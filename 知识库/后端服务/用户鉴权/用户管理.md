# 用户管理

## 对应代码路径

| 文件 | 说明 |
|---|---|
| `server/api/users.py` | admin only 用户 CRUD REST（256 行） |
| `server/models/user.py` | User ORM 模型（兼容期保留，53 行） |
| `server/lifecycle/seed.py` | 启动建表 + 默认账号 seed + migrations（122 行） |
| `server/tables/users.py` | tables 层 Users（实际 DB I/O 走这里） |

## 功能概述

- **用户 CRUD**（全部 require_admin）：
  - `GET /api/users` — 列表（keyword 内存模糊过滤 username/email/full_name + role 精确过滤）
  - `POST /api/users` — 创建（用户名正则 + 密码≥6 位 + 角色白名单 + 重名 409）
  - `PATCH /api/users/{user_id}` — 更新 role/email/full_name/is_active（含 admin 降权/禁用保护）
  - `POST /api/users/{user_id}/reset-password` — admin 重置任意用户密码
  - `DELETE /api/users/{user_id}` — 删除（不能删自己；删除最后一个 admin 拒绝）
- **默认账号 seed**：users 表为空时创建 admin/admin123（role=admin）与 trader/trader123（role=trader），均 `must_change_password=True`；已有用户则不做任何事
- **启动流程**：`init_and_seed()` 在 FastAPI startup 调用 → validate_config → init_db（create_all）→ `_run_pending_migrations()`（自研迁移追踪）→ seed

### 2. 列表（内存过滤）

```python
@router.get("", response_model=List[UserResponse])
def list_users(keyword=None, role=None, _=Depends(require_admin)):
    if role:
        users = Users.query_by("role", role)     # role 精确过滤走 tables 单字段查询
    else:
        users = Users.query_all()                # 数据量小，全表
    if keyword:                                  # keyword 三字段内存模糊（大小写不敏感）
        kw = keyword.lower()
        users = [u for u in users
                 if (u.username and kw in u.username.lower())
                 or (u.email and kw in u.email.lower())
                 or (u.full_name and kw in u.full_name.lower())]
    return [UserResponse(**_format_row_dict(u)) for u in users]
```

`_format_row_dict`：`row.to_dict()` 后把 created_at/updated_at/last_login_at 用 `format_db_dt` 转 str（UserResponse 期望 str）。

### 3. 创建

```python
@router.post("", status_code=201)
def create_user(payload: UserCreateRequest, _=Depends(require_admin)):
    _validate_username(payload.username); _validate_password(payload.password); _validate_role(payload.role)
    if Users.query_by("username", payload.username, limit=1):
        raise HTTPException(409, detail="用户名已存在")
    now = datetime.now(timezone.utc).replace(tzinfo=None)   # created_at/updated_at NOT NULL 无 SQL 默认，须显式填
    user_row = Users.add_one({
        "username": ..., "password_hash": hash_password(payload.password),
        "role": payload.role, "email": ..., "full_name": ...,
        "is_active": payload.is_active, "must_change_password": False,
        "created_at": now, "updated_at": now,
    })
    return UserResponse(**_format_row_dict(user_row))
```

### 4. 更新（admin 保护逻辑）

```python
@router.patch("/{user_id}")
def update_user(user_id, payload: UserUpdateRequest, admin=Depends(require_admin)):
    user = Users.query_one(id=user_id)             # 404 if missing
    data = {}
    if payload.role is not None:
        _validate_role(payload.role)
        # 保护 1: 降权最后一个 admin 拒绝
        if user.role == "admin" and payload.role != "admin":
            admin_count = aggregate("users", "COUNT", "*",
                                    where="`role` = %s AND `is_active`", params=("admin",))
            if admin_count <= 1: raise HTTPException(400, "必须至少保留一个管理员")
        data["role"] = payload.role
    if payload.is_active is not None:
        # 保护 2: 不能禁用自己
        if user.id == admin.id and not payload.is_active: raise HTTPException(400, "不能禁用当前登录账号")
        # 保护 3: 禁用最后一个启用的 admin 拒绝
        if user.role == "admin" and not payload.is_active:
            admin_count = aggregate(... 同上 ...)
            if admin_count <= 1: raise HTTPException(400, "必须至少保留一个启用的管理员")
        data["is_active"] = payload.is_active
    # email / full_name: strip 空串转 None
    if data: user = Users.update_one(data, id=user.id)
```

`aggregate(table, 'COUNT', '*', where=..., params=...)` 是 tables 层聚合工具，替代 `db.query(User).count()`。

### 5. 重置密码 / 删除

```python
@router.post("/{user_id}/reset-password")
def reset_password(user_id, payload: PasswordResetRequest, _=Depends(require_admin)):
    _validate_password(payload.new_password)
    user = Users.query_one(id=user_id)                    # 404
    Users.update_one({"password_hash": hash_password(payload.new_password)}, id=user.id)
    return {"success": True, "message": "密码已重置"}

@router.delete("/{user_id}")
def delete_user(user_id, admin=Depends(require_admin)):
    if user_id == admin.id: raise HTTPException(400, "不能删除当前登录账号")
    user = Users.query_one(id=user_id)                    # 404
    if user.role == "admin":
        admin_count = aggregate("users", "COUNT", "*", where="`role` = %s", params=("admin",))
        if admin_count <= 1: raise HTTPException(400, "必须至少保留一个管理员")
    Users.delete_one(id=user.id)
    return {"success": True}
```

注意：reset/delete **不撤销**该用户已登录 token（session cache 中仍有效至 idle 超时）；如需立即踢下线，需遍历 revoke。

### 6. seed 与 migrations（lifecycle/seed.py）

```python
def init_and_seed():                       # FastAPI startup 钩子
    validate_config(); init_db()           # SQLAlchemy create_all
    try: _run_pending_migrations()         # 失败仅打印，继续启动
    except Exception: traceback.print_exc()
    db = SessionLocal()
    count = db.query(User).count()
    if count == 0:                         # 仅空表 seed，已有用户不覆盖不重置
        db.add(User(username="admin", password_hash=hash_password("admin123"),
                   role="admin", full_name="系统管理员", is_active=True, must_change_password=True))
        db.add(User(username="trader", password_hash=hash_password("trader123"),
                   role="trader", full_name="默认交易员", is_active=True, must_change_password=True))
        db.commit()
```

## 依赖关系

- **tables 层**：`Users.query_one/query_by/query_all/add_one/update_one/delete_one`、`aggregate`
- **鉴权**：require_admin（auth/deps.py）；hash_password（auth/security.py，bcrypt rounds=12）
- **ORM**：models/user.py（seed 与 deps 兼容期仍用；列定义是 users 表 DDL 的事实源之一）
- **启动时序**：main.py startup → init_and_seed；必须先于任何用户请求
- **首登改密联动**：seed 置 must_change_password=True；login 返回 must_change_password_effective（受 sysconfig.must_change_password_required 开关控制，关闭后 seed 账号也不再拦截）

## 修改指南

- **放宽/收紧密码规则**：改 `_validate_password`（当前仅 ≥6 位，用户明令不加复杂度限制）；改密端点 auth.py 的 change-password 无此校验，两处需同步
- **新增用户字段**（如手机号）：① models/user.py 加列 ② server/migrations/ 加 ALTER 迁移脚本 ③ UserCreateRequest/UserUpdateRequest/UserResponse 加字段 ④ _row_to_user_dict（auth.py）按需同步
- **删除用户同时踢下线**：session cache 按 SHA256(token) 索引，无法按 user_id 反查；需在 cache 条目加 user_id 反查或遍历 `_TOKEN_CACHE`
- **改 seed 账号**：只影响**空表首次启动**；已有库改代码不会重置密码（手动 UPDATE users 或用 reset-password 端点）
- **新增 migration**：server/migrations/ 下新建 `NNN_描述.py`，导出 `def migrate(engine)` 或 `def upgrade()`；文件名排序即执行顺序；幂等由 _applied_migrations 保证，但脚本内部仍应自幂等
- **用户名规则**：改 USERNAME_RE 后注意已有用户名仍合法（校验只在创建时），登录不受影响
