# 交易会话与时钟

## 对应代码路径

| 文件 | 说明 |
|---|---|
| `server/api/admin/session.py` | 交易时段配置 GET/PATCH（54 行） |
| `server/api/clock.py` | 前端轮询时钟接口（62 行） |
| `server/api/system.py` | active-day 查询（45 行） |
| `server/services/sysconfig/__init__.py` | trdtime 配置存储 + `parse_trdtime` 解析 |
| `server/repo/system.py` | `TradingClock` 时段判断（被引用，非本模块） |

## 功能概述

交易时段体系围绕「三屏障」构建——**屏障 1 交易时段内、屏障 2 交易日已初始化、屏障 3 RPC 健康**。本模块覆盖前两屏障的查询与配置：

1. **交易时段配置**（trdtime）：格式 `HHMMSS-HHMMSS;HHMMSS-HHMMSS`（分号分隔多段），默认 `093000-113000;130000-153000`（A 股上午/下午两段）。存 sysconfig.user='0'，PATCH 后清 `TradingClock._loaded_at` 缓存立即生效。
2. **时钟轮询**（`GET /api/trading/clock`）：前端定时轮询，返回当前是否在时段内、下一段何时开始、还差多少秒。
3. **激活交易日**（`GET /api/system/active-day`）：返回标准 RPC 格式的当前交易日，前端 holdings 缓存用它做**推送守门**——broker 推送带 trd_date 时只接受与激活日匹配的记录，避免前一交易日未平委托的错误状态被应用到今天的缓存。

## 核心实现

### 1. 交易时段配置（admin/session.py）

```python
class SessionOut(BaseModel):
    trdtime: str          # "093000-113000;130000-153000"
    is_half_day: bool

class SessionUpdate(BaseModel):
    trdtime: Optional[str] = None
    is_half_day: Optional[bool] = None

@router.get("", response_model=SessionOut)
async def get_session(_user=Depends(get_current_user)):        # 登录即可读
    from server.repo.system import TradingClock
    win = TradingClock.get_session_window()
    return SessionOut(trdtime=sysconfig.get_trdtime_str(),
                      is_half_day=win.get("is_half_day", False))

@router.patch("", response_model=SessionOut, dependencies=[Depends(require_admin)])
async def update_session(req: SessionUpdate, user=Depends(get_current_user)):  # admin 才能改
    if req.trdtime is not None:
        parsed = sysconfig.parse_trdtime(req.trdtime)          # 格式校验
        if not parsed:
            raise HTTPException(400, detail=f"invalid trdtime format: {req.trdtime!r}")
        sysconfig.set_value("0", "trdtime", req.trdtime,
                            "交易时段 (分号分隔多段 HHMMSS-HHMMSS)", user.username)
        from server.repo.system import TradingClock
        TradingClock._loaded_at = None                         # 清缓存，立即生效
    return await get_session(user)
```

注意：`is_half_day` 当前仅回显（来自 TradingClock），PATCH 不会持久化它。

### 2. trdtime 解析（services/sysconfig/__init__.py）

```python
DEFAULT_TRDTIME = "093000-113000;130000-153000"

def parse_trdtime(s: str) -> list[tuple]:
    """'093000-113000;130000-153000' → [(time(9,30), time(11,30)), (time(13,0), time(15,0))]"""
    out = []
    for seg in s.split(";"):
        seg = seg.strip()
        if not seg or "-" not in seg: continue
        a, b = seg.split("-", 1)
        out.append((_hms_to_time(a), _hms_to_time(b)))
    return out

def _hms_to_time(hms: str):
    hms = hms.strip().zfill(6)
    return time(int(hms[0:2]), int(hms[2:4]), int(hms[4:6]))
```

### 3. 时钟轮询（api/clock.py）

```python
@router.get("/clock")
async def get_trading_clock():
    db = SessionLocal()
    try:
        active_trd = resolve_active_trd_date(db)       # sys_status id=1 的 trd_date（None=未日初）
        initialized = active_trd is not None
        default_trd = resolve_default_trd_date(db)
        is_in = TradingClock.is_in_trading_session()    # 当前时刻是否在任一时段内
        # 优先读 sysconfig.trdtime，回退默认
        trdtime_raw = sysconfig.get_raw("trdtime", user="0") or "093000-113000;130000-153000"
        sessions = _parse_trdtime(trdtime_raw)          # '093000-113000' → {start:'09:30:00', end:'11:30:00'}
        win = {"morning": sessions[0] if len(sessions) >= 1 else {...默认上午...},
               "afternoon": sessions[1] if len(sessions) >= 2 else {...默认下午...},
               "is_half_day": False} if sessions else TradingClock.get_session_window()
        nxt = TradingClock.next_session_start()
        secs = TradingClock.seconds_until_session()
    finally:
        db.close()
    return {
        "trading_day": active_trd,               # 无日初时 None
        "trading_day_initialized": initialized,
        "default_trading_day": default_trd,
        "is_in_session": is_in,
        "current_time": datetime.now().isoformat(),
        "session_window": win,
        "next_session_start": nxt.isoformat() if nxt else None,
        "seconds_until_session": secs,
    }
```

`_parse_trdtime`（clock.py 本地版）把 `HHMMSS` 转成 `HH:MM:SS` 字符串对；不足 2 段时用兜底窗口（上午 `00:00:00-11:30:00`、下午 `11:30:00-23:59:00`）。

### 4. 激活交易日（api/system.py）

```python
@router.get("/active-day")
async def get_active_day(user=Depends(get_current_user)):
    db = SessionLocal()
    try:
        trd_date = resolve_active_trd_date(db)
    finally:
        db.close()
    if trd_date is None:
        return {"code": 0, "msg": "no active trading day", "list": []}   # 未日初≠错误
    return {"code": 0, "msg": "", "list": [{"trd_date": trd_date, "status": "active"}]}
```

返回标准 RPC 格式 `{code, msg, list}`，与 broker RPC 响应结构一致，前端可复用同一解析逻辑。本端点**无鉴权依赖注入 admin**，仅需登录（get_current_user）。

## 依赖关系

- **配置存储**：sysconfig（trdtime 键，user='0'；详见《系统配置.md》）
- **TradingClock**（server/repo/system.py）：`is_in_trading_session` / `get_session_window` / `next_session_start` / `seconds_until_session`，内部有 `_loaded_at` 单例缓存（PATCH trdtime 后置 None 强制重载）
- **guards**：`resolve_active_trd_date`（读 sys_status id=1 行 trd_date）、`resolve_default_trd_date`
- **鉴权**：get_current_user（读）、require_admin（改 trdtime）
- **前端**：时钟轮询驱动下单按钮禁用态；active-day 用于 holdings IndexedDB 缓存推送守门

## 修改指南

- **改默认交易时段**：改 `services/sysconfig/__init__.py` 的 `DEFAULT_CONFIGS` 中 `trdtime` 项与 `DEFAULT_TRDTIME` 常量（两处保持一致）；已有 DB 行不会被覆盖（`_ensure_defaults` 只补缺失键），需手动 PATCH 或删 sys_config 行
- **支持 3 段以上时段**：`parse_trdtime` 天然支持 N 段；但 `clock.py` 的 `win` 只取前 2 段（morning/afternoon），第 3 段会丢失——需改 `get_trading_clock` 的 win 构造与前端展示
- **支持 is_half_day 持久化**：`update_session` 目前忽略 `req.is_half_day`；如需持久化，仿 trdtime 加 sysconfig 键（如 `is_half_day`），并让 TradingClock 读它
- **active-day 增加更多字段**：保持 `{code, msg, list}` 外层格式不变（前端按 RPC 标准格式解析），只在 list 元素内加字段
- **轮询频率**：由前端控制（建议 ≥5s），后端无缓存每次都查 DB；如压力大可在 clock 端点加 1s 内存缓存
