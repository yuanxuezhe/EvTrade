# 日初初始化

## 对应代码路径

| 文件 | 说明 |
|---|---|
| `server/api/admin/sys_status.py` | 日初初始化 REST 端点（v_next 重构版，242 行） |
| `server/services/reconcile.py` | 对账算法 `do_reconcile`（由本模块调用） |
| `server/services/push/pos.py` | `suppress_pos_push` 上下文管理器（抑制 pos_push 洪峰） |
| `server/ws/manager.py` | `ws_manager.broadcast`（system_update 通道） |

## 功能概述

日初初始化（`POST /api/admin/sys-status/init`）是每个交易日开始时的核心动作，由 admin 手动触发。整个流程：

1. **前置校验**：`trd_date` 必须 8 位数字；RPC 健康检查（`Depends(require_rpc_ok)`，状态非 0 直接 503 拦截）
2. **记录前一交易日**：读 `sys_status` 表 id=1 行的 `trd_date` 作为 `previous_trd_date`
3. **广播 `init_start`**：前端据此打开「初始化推送丢弃门」，丢弃 reconcile 期间的 pos_push/ord_cfm/trd_cfm 洪峰
4. **执行对账**：`with suppress_pos_push():` 包裹 `do_reconcile(db, trd_date, by_user, reconcile_kind='init')`
5. **失败路径**：`db.commit()`（保留报告）+ 广播 `init_aborted`（前端关门，否则推送被永久丢弃）+ 返 code=1
6. **成功路径**：读回 id=1 行 → 广播 `init_completed`（前端关门 + `resetForNewDay` 全量拉权威数据）→ 返回完整 `SysStatusOut`

关键设计：`sys_status` 是**单行宽表**（id=1，DB 层 CHECK id=1），切日 = UPDATE 同一行的 `trd_date`，历史交易日从 `reconcile_report.trd_date` 查。

## 核心实现

### 1. 请求/响应模型

```python
class InitRequest(BaseModel):
    trd_date: str          # 8 位数字字符串，如 "20260816"
    mode: str = "auto"     # auto | manual

class InitResponse(BaseModel):
    code: int = 0          # 0=成功 1=失败
    msg: str = ""
    report_id: Optional[int] = None   # 即 created_at 时间戳（int 秒）
    applied: bool = False
    trading_day: Optional[SysStatusOut] = None
    error: Optional[str] = None

class SysStatusOut(BaseModel):
    trd_date: str
    status: str                      # active / closed / initializing
    is_half_day: int = 0
    activated_at / activated_by / closed_at / closed_by: Optional
    remark: str = ""
    updated_at: Optional[str] = None
```

字段名直接对齐前端 `SystemInit.vue`。`activated_at` 映射 DB 列 `initialized_at`，用 `format_db_dt()` 格式化为 `"YYYY-MM-DD HH:MM:SS.fff"`。

### 2. WS 广播 helper（fire-and-forget）

```python
def _broadcast_init_change(change_kind, status, trd_date, previous_trd_date, report_id):
    try:
        from server.ws.manager import ws_manager
        _ts = datetime.now(timezone.utc).replace(tzinfo=None).isoformat()
        asyncio.ensure_future(ws_manager.broadcast(
            'system_update',
            {
                'type': 'system_status_change',
                'change_kind': change_kind,   # init_start / init_aborted / init_completed
                'trd_date': trd_date,
                'previous_trd_date': previous_trd_date,   # 前端推送守门用
                'status': status,             # initializing / error / ok / partial
                'report_id': report_id,
                'ts': _ts,
            },
            trace_id=f"init:{trd_date}:{report_id or 'start'}:{change_kind}",
        ))
    except Exception as _e:
        logging.getLogger(__name__).warning("init_trading_day ws broadcast failed (%s): %s", ...)
```

- 用 `asyncio.ensure_future` 不阻塞 HTTP 响应
- 广播失败仅 warning，不影响日初主流程
- 失败路径**必须**补发 `init_aborted`，否则前端「推送丢弃门」永远开着

### 3. init_trading_day 主流程（关键代码摘录）

```python
@router.post("/init", response_model=InitResponse,
             dependencies=[Depends(require_rpc_ok)])   # 路由层拦截
async def init_trading_day(req, db=Depends(get_db), admin_user=Depends(require_admin)):
    # (1) 校验
    if len(req.trd_date) != 8 or not req.trd_date.isdigit():
        raise HTTPException(400, detail={"code": "BAD_TRD_DATE", ...})
    by_user = str(admin_user.id)

    # (2) 读前一交易日（UPDATE 前的 id=1 行 trd_date）
    prev = db.query(SysStatus).filter(SysStatus.id == 1).first()
    _previous_trd_date = prev.trd_date if prev else None

    # (3) 广播 init_start → 前端开推送丢弃门
    _broadcast_init_change('init_start', 'initializing', req.trd_date, _previous_trd_date, None)

    # (4) 抑制 pos_push 后执行 init 对账（全表覆盖 positions）
    from server.services.push.pos import suppress_pos_push
    with suppress_pos_push():
        result = await do_reconcile(db, req.trd_date, by_user, reconcile_kind='init')

    # (5) 失败：提交报告 + init_aborted + code=1（HTTP 200，业务码标记失败）
    if not result['ok']:
        db.commit()
        _broadcast_init_change('init_aborted', 'error', req.trd_date,
                               _previous_trd_date, result['report_id'])
        return InitResponse(code=1, msg=result['error'] or '对账失败', applied=False, ...)

    # (6) 成功：读回 id=1 行（切日已在 do_reconcile 内完成）
    row = get_active_sysstatus(db)
    _init_status = 'partial' if result.get('error') else 'ok'
    _broadcast_init_change('init_completed', _init_status, req.trd_date,
                           _previous_trd_date, result['report_id'])
    return InitResponse(code=0, msg="日初完成", trading_day=SysStatusOut(...))
```

### 4. 抑制 pos_push 的原因（suppress_pos_push）

`do_reconcile(reconcile_kind='init')` 全表覆盖 positions 时，broker 并发 pos_push 逐条判「新增/变化」会引发广播洪峰；但 init 成功后前端 `resetForNewDay` 会 RPC 全量拉权威数据，窗口期 pos_push 冗余 → 用 `with suppress_pos_push():` 抑制（跨进程互斥上下文管理器）。**incremental（manual reconcile）不动 positions，不需要抑制。**

### 5. 仅对账端点（不切日）

```python
@router.post("/reconcile", response_model=InitResponse)
async def reconcile_only(req: ReconcileRequest, db, admin_user):
    result = await do_reconcile(db, req.trd_date, by_user, reconcile_kind='incremental')
    db.commit()
    return InitResponse(code=0 if result['ok'] else 1, applied=False, ...)
```

incremental 模式只生成报告，不覆盖 positions（pos_push 已接管），也不切日。

## 依赖关系

- **上游**：`require_rpc_ok`（server/api/deps.py，依赖 rpc_health.check_ok）；`require_admin`（server/services/guards.py）
- **下游调用**：`do_reconcile`（services/reconcile.py）；`suppress_pos_push`（services/push/pos.py）；`ws_manager.broadcast`（ws/manager.py）
- **数据表**：`sys_status`（单行 id=1）、`reconcile_report`（历史交易日来源）、`positions`、`assets`
- **前端契约**：WS `system_update` 通道 `type='system_status_change'`，`change_kind` 三态驱动推送丢弃门

## 修改指南

- **新增日初步骤**（如清空日内缓存）：加在 `do_reconcile` 成功之后、`_broadcast_init_change('init_completed', ...)` 之前，确保前端收到的 completed 事件对应已完成全部初始化
- **修改广播字段**：同步更新前端 `SystemInit.vue` / WS 消息处理器；`change_kind` 三值（init_start/init_aborted/init_completed）是前后端契约，不可改名
- **修改返回结构**：`InitResponse.trading_day` 字段名与前端对齐，改动需前后端同步
- **放开 RPC 拦截**：删除 `dependencies=[Depends(require_rpc_ok)]` 即可，但强烈不建议——RPC 断连时对账必然失败
- **历史交易日查询**：v_next 已删除 `GET /api/admin/sys-status` 列表端点，历史走 `GET /api/admin/reconcile/reports`
- **trd_date 校验收紧**（如必须大于当前日期）：改 `init_trading_day` 开头的 `len(req.trd_date) != 8 or not req.trd_date.isdigit()` 判断
