## 功能概述

v78 起 EvTrade 把 fee_config / reconcile_config / trading_session 三套旧配置整合为**统一 sys_config 表 + 进程内 cache**：

- **存储模型**：`sys_config` 表，PK=(user, cfg_key)。`user='0'` 表示系统默认；`user='<username>'` 为用户专属覆盖。
- **读策略**：`get(key, default, user)` → 先查 user 行，缺失回退 user='0' 默认；类型按 default 的类型自动 coerce（bool/int/float/str）。
- **写策略**：`set_value(user, key, val)` → 同步更新 cache + DB（upsert）。
- **加载**：启动时 `load_all()` 一次性全表加载进内存 `_cache`，业务层全部从 cache 读（微秒级）。
- **权限**：admin 可写 user='0' 默认与任意用户；普通用户只能读写自己的；`GET /api/sysconfig` 普通用户看到「自己的 + 继承的默认」。

费率四键（2026-08-12 规则：万 1 免五、无印花税）：
`commission_rate=0.0001`（佣金）、`stamp_tax_rate=0`（印花税）、`slippage=0.001`（滑点）、`min_commission=0`（最低佣金，0=免五）。

## 核心实现

### 1. 内存 cache（services/sysconfig/__init__.py）

```python
_lock = threading.RLock()
_cache: dict[str, dict[str, str]] = {}       # user → {cfg_key → cfg_val}
_desc_cache: dict[str, dict[str, str]] = {}  # desc 旁路 cache（list_all UI 展示用）
_loaded: bool = False

def load_all(db=None) -> None:
    _ensure_defaults()                        # 缺失的默认键 upsert 进 DB
    rows = SysConfig.query_all()
    with _lock:
        new_cache = {}; new_desc = {}
        for r in rows:
            new_cache.setdefault(r.user, {})[r.cfg_key] = r.cfg_val
            new_desc.setdefault(r.user, {})[r.cfg_key] = r.desc or ""
        _cache.clear(); _cache.update(new_cache)
        _desc_cache.clear(); _desc_cache.update(new_desc)
        _loaded = True
```

### 2. 读（类型 coerce + 回退）

```python
def _coerce(val: str, default):
    if isinstance(default, bool):  return val.lower() in ("1", "true", "yes", "on")
    if isinstance(default, int):   return int(val)  # 失败回退 default
    if isinstance(default, float): return float(val)
    return val

def get(key: str, default=None, user: str = "0"):
    with _lock:
        user_dict = _cache.get(user, {})
        if key in user_dict:  return _coerce(user_dict[key], default)   # 用户覆盖优先
        default_dict = _cache.get("0", {})
        if key in default_dict:  return _coerce(default_dict[key], default)  # 回退默认
    return default

def get_raw(key, user="0") -> Optional[str]:   # 不 coerce，返回原始 str
```

### 3. 写（cache + DB 同步）

```python
def set_value(user, key, val, desc="", updated_by=None):
    row = SysConfig.query_one(user=user, cfg_key=key)
    if row:
        row.cfg_val = val
        if desc: row.desc = desc
        row.updated_by = updated_by
        row.update(SysConfig, user=user, cfg_key=key)      # updated_at 由 DB DEFAULT 更新
    else:
        SysConfig.add_one({"user": user, "cfg_key": key, "cfg_val": val,
                           "desc": desc or "", "updated_by": updated_by})
    with _lock:
        _cache.setdefault(user, {})[key] = val
        _desc_cache.setdefault(user, {})[key] = desc

def delete_value(user, key) -> bool:
    ok = SysConfig.delete_one(user=user, cfg_key=key)
    if ok:  # 同步删 cache
        del _cache[user][key]
    return ok
```

### 4. REST 权限模型（api/sysconfig.py）

```python
# 写权限三查（POST/PUT/DELETE 通用模式）:
target_user = body.user if body.user is not None else current.username
if target_user == "0" and current.role != "admin":
    raise HTTPException(403, detail={"code": "FORBIDDEN", "msg": "only admin can write user='0' defaults"})
```

`list_all(user)`（服务层）返回 `[{user, cfg_key, cfg_val, desc, has_override, inherited}]`；user 查询时自动补上 user='0' 中未覆盖的键并标 `inherited=True`，`has_override` 标记默认键被某用户覆盖。

### 5. 费率路由（api/fee_config.py）

```python
@router.get("", response_model=FeeConfigOut)
async def get_fee_config_route(_user=Depends(get_current_user)):    # 登录可读
    return FeeConfigOut(**sysconfig.get_fee_dict(user="0"))

@router.patch("", dependencies=[Depends(require_admin)])            # admin 可改

    if req.commission_rate is not None:
        sysconfig.set_value("0", "commission_rate", str(req.commission_rate), "佣金费率 (万一)", user.username)
```

## 依赖关系

- **数据表**：`sys_config`（PK: user+cfg_key），v81 tables-migration 后 DB I/O 全走 `server.tables.SysConfig`
- **启动时序**：main.py lifespan → `sysconfig.load_all()`（须在任何业务读配置前完成；未加载时 get 回退 default）
- **消费方**：fee_config（费率）、admin/reconcile（对账配置）、admin/session + clock（trdtime）、auth.py（must_change_password_required）、下单链路（cantrdstktypes 过滤可交易标的）
- **鉴权**：get_current_user（读）+ require_admin（写 user='0'）

## 修改指南

- **新增系统配置键**：在 `DEFAULT_CONFIGS` 列表追加 `{"cfg_key": ..., "cfg_val": ..., "desc": ...}`；启动时 `_ensure_defaults` 自动补种到 DB；业务侧 `sysconfig.get("new_key", default)` 读取
- **新增便捷 helper**：仿 `get_fee_dict`，定义 `KEYS` dict + `def get_xxx_dict(user="0")`，一行 dict comprehension
- **cache 与 DB 不一致排查**：所有写必须走 `set_value`/`delete_value`（它们同步双写）；直接改 DB 不会刷新 cache，需重启或手动 `load_all()`
- **多进程部署注意**：cache 是进程内的（v128.4 单进程回归决策）。若启用 `--workers N`，A 进程 set_value 后 B 进程 cache 不感知——恢复单进程或引入失效广播
- **配置值长度**：`SysConfigUpsert` 限制 cfg_val ≤512、desc ≤255、cfg_key ≤64 字符
- **费率键改名**：同步改 `FEE_KEYS` dict 与 `api/fee_config.py` 的 `FeeConfigOut/FeeConfigUpdate` 模型，旧 DB 行需手动迁移
