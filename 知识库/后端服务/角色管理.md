## 功能概述

把硬编码 admin/trader/viewer 字符串的 RBAC 升级为**多对多角色 + 页面权限**配置：

- **角色**：4 预置 (super_admin / admin / trader / viewer) + 任意自定义
- **用户 ↔ 角色**：多对多 (一个用户多个角色，权限取并集)
- **角色 ↔ 页面权限**：`page_key` 是前端路由唯一 key；任一 role 含 `'*'` 通配 = 全通过

## 数据模型 (3 张表)

```
roles (id PK, name UK, display_name, description, is_builtin, created_at, updated_at)
  └─ is_builtin=1 → 内置不可删 (super_admin / admin / trader / viewer)

user_roles (user_id FK, role_id FK, granted_at, granted_by)
  └─ PK (user_id, role_id), CASCADE 删除

role_permissions (role_id FK, page_key, granted_at)
  └─ PK (role_id, page_key), page_key='*' 表通配
```

## 4 预置 role + 默认 page_keys

| role | display | n page | page_keys |
|---|---|---|---|
| super_admin | 超级管理员 | 1 | `*` (通配) |
| admin | 管理员 | 13 | dashboard, asset, cache-asset/-orders/-positions/-trades, admin-stock-config, data-completion-history-quote, roles, stkpool, system-config, system-init, users |
| trader | 交易员 | 11 | dashboard, asset, trade, t0-trade, strategy-order, script-dev, script-task, stkpool, stkpool-view, cache-orders, cache-trades |
| viewer | 观察者 | 5 | dashboard, asset, cache-orders, cache-trades, cache-positions |

## API 端点 (全 require_admin)

```
GET    /api/roles                          列出所有角色 + 各自 page_keys
GET    /api/roles/{id}                     单角色详情
POST   /api/roles                          新建角色
PATCH  /api/roles/{id}                     改 display_name / description (name + is_builtin 不可改)
DELETE /api/roles/{id}                     删角色 (内置 is_builtin=1 不可删, 400)
GET    /api/roles/{id}/permissions         该角色 page_keys
PUT    /api/roles/{id}/permissions         整体覆盖 page_keys (super_admin 必保留 '*', 400)
GET    /api/roles/users/{user_id}/roles    用户已绑定角色
PUT    /api/roles/users/{user_id}/roles    整体覆盖用户角色 (最后 super_admin 不可解, 400)
```

## 4 道防锁死

1. 内置 role 不可 DELETE → 400 `BUILTIN_ROLE`
2. super_admin 不能去掉 `'*'` → 400 `SUPER_ADMIN_NEEDS_WILDCARD`
3. 不能解绑最后 super_admin → 400 `LAST_SUPER_ADMIN`
4. role_name 不存在 → 404 `ROLE_NOT_FOUND`

## 向后兼容

| 旧 | 新 | 兼容方式 |
|---|---|---|
| `users.role` 字符串 ('admin'/'trader'/'viewer') | `user_roles` 多对多关联 | 保留字段; PATCH 时按 `role_names` 自动派生 (`derive_users_role_from_names` 优先级 super_admin > admin > trader > viewer); 前端 `hasPageKey()` 老 user fallback |
| `requiresAdmin / requiresTrader` router 守卫 | `meta.pageKey` + `hasPageKey` | 保留旧 meta 作 fallback (`hasRbac` 判定); 老 store 无 roles 字段时宽松 |
| 前端 `isAdmin / isTrader` 字符串 store | RBAC `userRoles / pageKeys` | 保留; `hasPageKey` 内嵌 fallback |

## 修改指南

- **新增 role**：`POST /api/roles` (新 role 自动 is_builtin=0, 可删)
- **给 role 加 page_key**：UI 进角色管理 → 选中 → 勾选 → 保存; 或 `PUT /api/roles/{id}/permissions`
- **给 user 绑 role**：UI 用户管理 → 编辑 → 勾选多角色 → 保存; 或 `PUT /api/roles/users/{uid}/roles`
- **新增路由必须**：在 `client/src/router/index.js` 加 `meta.pageKey` + 在 `client/src/utils/pageNavTree.js` 添加到对应业务域 (否则 Sidebar 不显示, Roles.vue 权限树不显示)
- **新增 page_key 类型** (如按钮级)：`role_permissions.page_key` 字段是 VARCHAR(64) 已支持; UI 加 group
- **改 4 预置 role 的 page_keys**：`UPDATE role_permissions` + 重启后端 (前端 hasPageKey 不会自动重载, 需用户重新登录触发 fetchMe)
- **首次部署**：`python3 server/migrations/2026-09-21-add-roles-user-roles-permissions.py` (幂等 INSERT IGNORE)
