# 配置说明

## 对应代码路径

- `server/config.py`（Settings / ConfigValidator / validate_config）
- `server/.env`、`server/.env.example`、`server/.env.dev`、`server/.env.prod`
- `server/infra/db.py`（EVTRADE_DB_* 池参数）、`server/alembic/env.py`（复用 EVTRADE_DB_URL）

## 功能概述

config.py 用 frozen dataclass 集中所有可调参数，启动时从 `server/.env`（python-dotenv，override=False）+ 环境变量加载。`validate_config()` 在 lifecycle/seed.py 启动时调用：错误（如 RABBITMQ_URL 缺失、端口非法）直接 RuntimeError 拒绝启动，警告仅打印。数据库连接相关配置不在 Settings 内，由 infra/db.py 自行读取。

## 文件清单
| 代码文件 | 作用 |
|----------|------|
| server/config.py | Settings 数据类 + _env/_env_int/_env_float 读取助手 + ConfigValidator |
| server/.env | 当前生效配置（git 忽略） |
| server/.env.example | 配置模板（含注释说明全部键） |
| server/.env.dev / .env.prod | 开发 / 生产环境配置副本（部署时拷为 .env） |

### .env 文件族
- `.env`：实际生效文件，config.py / infra/db.py / alembic env.py / migrations 脚本各自 load_dotenv（幂等，override=False）。
- `.env.example`：模板，含 RabbitMQ / RPC / FastAPI / DB / JWT / hqserver / 历史 K 线全部键及注释。
- `.env.dev` / `.env.prod`：按环境维护的两份副本，部署时复制为 `.env`。（早期文档提到的 `.env.gs` / `.env.sc` 已不存在，以现仓文件为准。）

### 不在 Settings 的关键环境变量
| 环境变量 | 读取处 | 默认 |
|----------|--------|------|
| EVTRADE_DB_URL | infra/db.py | 无（缺失直接 RuntimeError，v20 MySQL-only） |
| EVTRADE_DB_ADMIN_URL | infra/db.py init_db | 降级用 EVTRADE_DB_URL |
| EVTRADE_DB_POOL_SIZE / _MAX_OVERFLOW / _POOL_RECYCLE / _POOL_PRE_PING / _POOL_TIMEOUT | infra/db.py | 20 / 30 / 1800 / true / 10 |
| EVTRADE_SECRET | auth/security.py | 空时自动生成写 server/auth/.secret_key |
| EVTRADE_CORS_ORIGINS | main.py | localhost:50998,3000,file://,null |
| HQ_UDP_BIND / QUOTA_UDP_HOST / QUOTA_UDP_PORT / HQ_NUM_WORKERS / HQ_MAX_QUEUE_SIZE / HQ_WS_PORT | hq/hqserverd (Rust, 取代旧 hqserver.py + RabbitMQ) | 见 .env.example |

### ConfigValidator
`validate() -> bool` 检查：
1. EVTRADE_SECRET 未设且无 .secret_key 文件 → 警告（首次启动自动生成）
2. RABBITMQ_URL 为空 → error
3. RPC_TIMEOUT ≤0 或 >300 → 警告（建议 5-120s）
4. API_PORT 不在 1-65535 → error
errors 非空时 `validate_config()` 抛 `RuntimeError("Config validation failed: ...")`。

## 依赖关系
- 上游：所有模块 `from server.config import settings`
- 下游：dotenv / os.environ；infra/db.py 独立读取 DB 类变量

## 修改指南
- 新增配置：在 Settings 加字段（用 _env/_env_int/_env_float 指定环境变量名与默认值），同步更新 .env.example；涉及启动必要项则在 ConfigValidator 加校验。
- 改队列名/交换机必须与 broker 端约定同步，durable 队列名改动需先清理 RabbitMQ。
- frozen dataclass：运行期不可赋值，需动态值请走独立模块级常量。
