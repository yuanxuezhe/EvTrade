# 入口与配置

## 对应代码路径

- `e:/EvTrade/strategy_exec/strategy_exec/main.py`（FastAPI 入口）
- `e:/EvTrade/strategy_exec/strategy_exec/config.py`（Pydantic Settings）
- `e:/EvTrade/strategy_exec/.env.example`（环境变量样例）
- `e:/EvTrade/strategy_exec/scripts/evctl_strategy_exec.py`（进程控制器）
- `e:/EvTrade/pyproject.toml`（依赖，复用根项目）

## 功能概述

main.py 提供 FastAPI app 工厂（`create_app`）与模块级单例 `app`（供 `uvicorn strategy_exec.main:app` 使用），并支持 `python -m strategy_exec.main` CLI 启动。config.py 用 pydantic-settings 从 `strategy_exec/.env` + 环境变量加载全部配置，强类型校验、fail-fast（必填缺失即退出）。

## 文件清单

| 代码文件 | 作用 |
|----------|------|
| `main.py` | app 工厂 / lifespan 钩子 / 日志配置 / CLI argparse 入口 |
| `config.py` | `Settings`（BaseSettings）+ `get_settings()` 单例 + `reload_settings()` |
| `.env.example` | 全部环境变量的样例与注释 |
| `scripts/evctl_strategy_exec.py` | start/stop/status/restart/logs 五个运维子命令 |
| `pyproject.toml`（根） | 依赖声明（无独立 pyproject，复用根 .venv） |

## 核心实现

### main.py 关键点

- `_setup_logging(level)`：`logging.basicConfig`，格式 `%(asctime)s [%(levelname)s] %(name)s: %(message)s`。
- **模块加载即配置日志**（main.py:72）：evctl 用 `uvicorn strategy_exec.main:app` 启动不会执行 `main()`，若不在 import 时配置日志，根 logger 停在 WARNING，各步骤 INFO 日志无法落盘。
- `lifespan(app)`：异步上下文管理器。启动时打 log（版本 / port / mysql / rabbitmq / hq_ws），关闭时仅打 shutting down。Phase 2 的 RabbitMQ publisher、DB engine 均为 lazy init，不在 lifespan 中创建。
- `create_app()`：`FastAPI(title="StrategyExec", version=__version__, lifespan=lifespan)`，挂 `health_router` + `internal_router`。
- `main()` CLI 参数：`--host` / `--port` / `--log-level` / `--reload`，默认值均来自 settings（env 覆盖：`STRATEGY_EXEC_HOST` / `STRATEGY_EXEC_PORT`）。

启动方式：

```bash
# 方式1: 直接 CLI（默认 8001）
python -m strategy_exec.main --port 8001

# 方式2: uvicorn（evctl 内部用的就是这条）
python -m uvicorn strategy_exec.main:app --host 0.0.0.0 --port 8001 --log-level info

# 方式3: 进程控制器（后台启动 + pid/log 文件管理）
python scripts/evctl_strategy_exec.py start|stop|status|restart|logs
```

### evctl_strategy_exec.py

仿 `server/scripts/evctl.py`，不依赖 EvTrade 代码。要点：

- pid 文件：`strategy_exec/logs/strategy_exec.pid`；日志：`strategy_exec/logs/strategy_exec.log`。
- 启动命令读 env `STRATEGY_EXEC_PORT`（默认 8001）、`LOG_LEVEL`；`subprocess.Popen(..., start_new_session=True)` 独立进程组。
- stop：SIGTERM 等 5s，未退则 SIGKILL。status 顺带 curl `http://127.0.0.1:{port}/health`。logs 优先 `tail -f`，无 tail 则 dump 最后 100 行。

### config.py 全部配置项

前缀约束：所有 env 必须为 `STRATEGY_EXEC_*`、`EVTRADE_*`、`HQ_*`、`SANDBOX_*` 之一；`case_sensitive=False`；`extra="ignore"`；env 文件为 `strategy_exec/.env`（存在才加载）。

| 字段（env 名大写） | 默认值 | 说明 |
|---|---|---|
| `STRATEGY_EXEC_PORT` | `8001` | 监听端口（1~65535） |
| `STRATEGY_EXEC_HOST` | `0.0.0.0` | 监听 host |
| `STRATEGY_EXEC_API_TOKEN` | `""` | internal API token；**空 = 不鉴权**（局域网部署） |
| `EVTRADE_DB_URL` | 必填（min_length=20） | MySQL 连接串（与 EvTrade 同库） |
| `EVTRADE_DB_POOL_SIZE` | `5` | 连接池大小（1~50） |
| `EVTRADE_DB_MAX_OVERFLOW` | `10` | 池溢出上限（0~50） |
| `EVTRADE_DB_POOL_RECYCLE` | `1800` | 连接回收秒数（≥60） |
| `EVTRADE_DB_POOL_PRE_PING` | `true` | 取连接前 ping |
| `EVTRADE_RABBITMQ_URL` | 必填（min_length=10） | RabbitMQ amqp URL（与 EvTrade 共享 broker） |
| `EVTRADE_STRATEGY_EXCHANGE_NAME` | `strategy.exchange` | signal 推送 exchange（topic, durable） |
| `EVTRADE_STRATEGY_SIGNAL_QUEUE` | `EvTrade.StrategySignal` | EvTrade 侧消费队列名（仅文档作用，本服务不声明） |
| `EVTRADE_STRATEGY_PUBLISH_CONFIRM_TIMEOUT` | `5` | publisher confirm 超时秒（1~60） |
| `EVTRADE_STRATEGY_PUBLISH_RETRIES` | `3` | publish 重试次数（0~10） |
| `EVTRADE_HIS_HQ_EXCHANGE_NAME` | `quota_his.exchange` | 历史 K 线请求 exchange（topic, durable） |
| `EVTRADE_HIS_HQ_REQ_QUEUE` | `EvTrade.ReqHisHq` | broker his_hq 监听的请求队列 |
| `EVTRADE_HIS_HQ_REQ_TIMEOUT` | `30` | his_hq 应答空闲超时秒（5~300） |
| `HQ_WS_URL` | `ws://127.0.0.1:8765/quota.broadcast` | hqserver 行情 WS 地址（实盘用） |
| `HQ_WS_RECONNECT_BASE_DELAY` | `1000` | WS 重连基础退避毫秒（≥100） |
| `HQ_WS_RECONNECT_MAX_DELAY` | `30000` | WS 重连最大退避毫秒（≥1000） |
| `HQ_WS_HEARTBEAT_INTERVAL` | `30` | WS ping 间隔秒（≥5） |
| `SANDBOX_BLOCKED_MODULES` | `os.system,subprocess,open,socket,requests,urllib,http.client` | 沙箱禁止 import 的顶层模块（逗号分隔） |
| `SANDBOX_ALLOWED_MODULES` | `backtrader,numpy,pandas,math,json,datetime,typing` | 沙箱允许 import 的顶层模块 |
| `LOG_LEVEL` | `INFO` | DEBUG/INFO/WARNING/ERROR/CRITICAL（validator 强校验并 upper） |
| `LOG_FILE` | `""` | 日志文件路径（当前代码未使用，实际日志由 evctl 重定向） |

辅助方法：`blocked_module_list()` / `allowed_module_list()` 把逗号串拆成 `List[str]`，供沙箱 `_safe_import` 使用。

### get_settings 单例

```python
@lru_cache(maxsize=1)
def get_settings() -> Settings: ...
```

启动时初始化一次；加载失败 `log.error` 后 `raise SystemExit`（fail-fast）。`reload_settings()` 清缓存重读（测试用）。

### Dockerfile / 独立打包说明

`strategy_exec/` 目录下**没有** Dockerfile，也没有独立 pyproject.toml —— 复用 EvTrade 根 `.venv` 与根 `e:/EvTrade/pyproject.toml`。所需依赖（fastapi、uvicorn、sqlalchemy、pymysql、aio-pika、backtrader、pandas、pydantic-settings、websockets、msgpacket）均已在根 pyproject 声明。部署时无需容器化，用 evctl 脚本在宿主机直接跑。

## 依赖关系

- 上游：`.env` / 环境变量；根 `.venv` 的全部依赖包。
- 下游：`api/`、`engines/`、`data_access/`、`signal/`、`market_data/`、`sandbox/` 全部模块均通过 `get_settings()` 读配置。

## 修改指南

- 新增配置项：在 `Settings` 加 Field（注意前缀约束与 min/max 校验），同步 `.env.example`；必填项不加默认值即 fail-fast。
- 改端口：优先改 `.env` 的 `STRATEGY_EXEC_PORT`，evctl 与 CLI 均会读取。
- 若未来做容器化：在 `strategy_exec/` 下补 Dockerfile（基于根 pyproject 安装依赖 + `uvicorn strategy_exec.main:app`），并更新本文件与《架构概览》。
