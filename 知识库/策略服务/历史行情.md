# 历史行情 (broker his_hq)

## 链路

```
strategy_exec.run_backtest()
  └─ strategy_exec.market_data.hq_history.fetch_his_bars()
       └─ sys_config.user='0' AND cfg_key='his_hq_test_mode' = '1' ?
            ├─ 是 (mock) → generate_mock_bars() 本地生成确定性 K 线
            └─ 否          → aio_pika publish 到 quota_his.exchange/EvTrade.ReqHisHq
                              └─ broker his_hq 异步答到 ans_queue
```

## 离线 mock 模式 (2026-08-29, change `2026-08-29-his-hq-mock`)

**Why**: Linux dev 环境无 xtquant / QMT broker 时，broker his_hq 不消费 `EvTrade.ReqHisHq` 队列 → `fetch_his_bars` 30s 超时 0 rows → run_backtest 抛 BROKER_ERROR 502 → 老 queued 任务永远卡 queued。

**触发**: `sys_config.user='0' AND cfg_key='his_hq_test_mode' = '1'` 时短路 RabbitMQ，调用 `generate_mock_bars()` 返确定性 K 线（不连 broker）。

**切换方式**:
```sql
-- 开 mock (offline 跑回测)
UPDATE sys_config SET cfg_val='1' WHERE user='0' AND cfg_key='his_hq_test_mode';

-- 关 mock (默认, 走真实 broker)
UPDATE sys_config SET cfg_val='0' WHERE user='0' AND cfg_key='his_hq_test_mode';
```

**首次部署**: `server/infra/db.py` `init_db` 兜底 seed `his_hq_test_mode=0`（与 `rpc_test_mode` 对称）。运行后会自动写入。

**启动日志**: `server/main.py` 启动时打印：
```
[INIT] HIS_HQ_TEST_MODE=1: strategy_exec.fetch_his_bars 不连 broker, 本地生成 K 线
[INIT] HIS_HQ_TEST_MODE=0: strategy_exec.fetch_his_bars 走真实 broker
```

## Mock K 线生成规则

| 维度 | 规则 |
|------|------|
| seed | `abs(hash(stock_code)) % (2**31)` → 同 stock_code 同区间 = 同数据（跨重启一致） |
| 起始价 | `50 + (seed % 100)` → 50~150 区间 |
| 日涨跌幅 | `random.Random(seed).gauss(0.0, 0.02)` → 约 2% 日波 |
| OHLC 关系 | `high ≥ max(open, close)`; `low ≤ min(open, close)` |
| 周末 | Sat / Sun 不生成 bar |
| period | 仅 `1d` 完整支持（其他 `1m/5m/15m/30m/60m` 返空，后续扩展） |
| stime 格式 | `YYYYMMDD150000`（14位, 对齐 broker 协议 + Backtrader `format="%Y%m%d%H%MSS"`） |
| volume | 基准 1,000,000 + seed 微扰 |

## 老 queued 任务清理 (admin only)

dev 环境无 broker 时，老 queued 任务会永远卡 queued。前端看到「排队中」但实际是历史遗留。admin 可手动清理：

```
POST /api/script-strategy/strategies/{strategy_id}/stale-queued/cleanup?threshold_hours=24
Authorization: Bearer <admin_token>
```

- admin only: 非 admin 返 403 FORBIDDEN
- strategy 不存在: 404 NO_STRATEGY
- 阈值默认 24h（与 `list_stale_queued_tasks` 视觉标记一致）
- 仅 UPDATE status='failed' + error_msg=回填原因（**不删行**，用户硬规则 2026-08-27）
- 返 `{strategy_id, cleaned_count, error_msg_template}`

**实测（2026-08-29）**:
- sid=3 cleanup cleaned_count=3 (id 3/4/5)
- sid=12 cleanup cleaned_count=1 (id 14, > 24h)
- sid=5 cleanup cleaned_count=1 (id 6, > 24h)
- task 15/16/17/20 (created_at < 24h) 不变 → 保留
