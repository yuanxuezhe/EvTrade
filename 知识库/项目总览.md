# 项目总览

## 一句话定位

A股智能交易终端：Vue3 + FastAPI + msgpacket RPC + XtQuant/QMT 柜台，覆盖行情推送、手动交易、T0 做T、策略回测与实盘的完整链路。

## 四大服务

| 服务 | 端口 | 代码目录 | 职责 |
|------|------|----------|------|
| 前端终端 | :50998 | `client/` | Vue3 + Element Plus + ECharts + Pinia，17 个页面 |
| EvTrade API | :8000 | `server/` | 交易核心、鉴权、系统管理、WebSocket 推送 |
| hqserver | :8765 | `hq/` | 独立行情 WebSocket，FANOUT 推送 |
| strategy_exec | :8001 | `strategy_exec/` | Backtrader 策略回测/实盘，信号经 RabbitMQ 推送 |

## 架构与数据流

```text
┌──────────────┐  REST + WS   ┌───────────────┐  msgpacket RPC  ┌──────────┐
│ Vue3 前端     │─────────────▶│ EvTrade API    │───────────────▶│ RabbitMQ │
│ (:50998)     │◀────────────│ (:8000)       │◀────────────────│          │
└──────┬───────┘   5 频道 WS   └───────┬───────┘  4类push        └────┬─────┘
       │ ws://:8765 直连                  │ signal_consumer 订阅       │ YSWY协议
       ▼                                  ▼                           ▼
┌──────────────┐               ┌───────────────┐               ┌──────────┐
│ hqserver     │◀── FANOUT ───│ strategy_exec  │── signal ───▶│ QMT 柜台  │
│ (:8765)      │               │ (:8001)       │               │ XtQuant  │
└──────────────┘               └───────────────┘               └──────────┘
```

### 核心数据流（v4 后）

- **下单**：Vue → `place()` → 本地 INSERT(status=48) → `ord_stk` RPC(remark=order_no) → status=49/55 → WS 推 Vue
- **推送**：QMT → `ord_cfm/trd_cfm/pos_cfm/ast_cfm` → push_handlers 写 DB → WS 推 Vue
- **查询**：纯 DB SELECT，不调 RPC；默认 trading_day = 激活日
- **日初**：Admin → `/api/admin/sys-status/init` → 对账 → 查 4 类数据 → 写报告 → 切交易日 → WS broadcast
- **策略信号**：strategy_exec 跑 Backtrader → signal → `strategy.exchange` → EvTrade signal_consumer → `/api/orders/place` 自动下单

## 技术栈

| 层 | 技术 |
|----|------|
| 前端 | Vue3、Element Plus、ECharts、Pinia、IndexedDB、vue-router |
| 后端 | FastAPI、SQLAlchemy(1.4)、uvicorn、python-jose(JWT)、passlib/bcrypt |
| 通信 | RabbitMQ（aio-pika/pika）、msgpacket（vendor wheel）、WebSocket |
| 策略 | Backtrader、pandas、numpy |
| 数据 | SQLite（本地业务）、MySQL（策略共享表） |
| 工具链 | uv（Python 管理）、pytest、alembic |

## 启动

```bash
uv run python scripts/evctl.py start    # 一键启动 backend/frontend/hqserver
uv run python scripts/evctl.py status   # 查看状态
```

默认账号 admin / admin123（首次启动 seed）。
